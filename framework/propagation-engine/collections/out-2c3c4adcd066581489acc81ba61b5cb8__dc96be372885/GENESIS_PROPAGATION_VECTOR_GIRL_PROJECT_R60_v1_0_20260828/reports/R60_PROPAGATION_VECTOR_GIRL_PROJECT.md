## 7. Transport vs Transduction solves the house problem

This is an important source-native distinction.

If an object moves while the declared dependency/base context stays fixed:

use **Transport**.

If the move changes the operative dependency/base context:

use **Transduction**.

Example:

Pillow moving locally across one declared room chart may be representable as Transport.

Pillow changing from a Sofa-supported relation to a Floor-supported relation may require
Transduction if the dependency/base context itself changes.

Thus "propagation" is not forced to be one universal operation.
It has at least two source-native modes:

`Propagation = Transport` when base context is fixed.

`Propagation = Transduction` when base context changes.

Both retain History/provenance under the Unified Transduction Object contracts.
