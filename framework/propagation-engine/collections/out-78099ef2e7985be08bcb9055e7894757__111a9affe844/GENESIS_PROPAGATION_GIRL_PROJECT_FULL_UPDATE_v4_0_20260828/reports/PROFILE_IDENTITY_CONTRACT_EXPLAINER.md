# PROFILE IDENTITY CONTRACT — EXPLAINER

The word is **contract**, not contact.

The generic mathematics now knows how identity comparison works structurally:
compare coherent closed recursive projection towers through active Resolution,
preserve History, and require commuting projection maps.

What is not generic is which attributes a particular profile declares essential.

A profile contract is therefore the list of invariants that must survive propagation
for the Projection Operator to say "same identity".

Example:

`Contract(square_profile) = {incidence, recursion, orientation?, History?, occupancy?}`.

Question marks matter:
different profiles may declare different invariants essential.

If orientation is not part of the contract, a reflected presentation may remain the same identity.
If orientation is part of the contract, reflection may produce a different identity class.

If metric ratios are not part of the contract, continuous deformation preserving incidence may be allowed.
If they are required, those deformations may break identity.

So the branch is not:
"What is identity?"

It is:
"For this particular closed fractal profile, which features are identity-bearing and which are presentation-only?"

Once a profile declares that contract, R72 already supplies the generic equivalence law.
