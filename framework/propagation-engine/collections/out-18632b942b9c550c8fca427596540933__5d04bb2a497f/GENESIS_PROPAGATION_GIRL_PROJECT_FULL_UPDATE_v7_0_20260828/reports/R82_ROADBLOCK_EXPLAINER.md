# R82 roadblock

We now know how to represent a universe containing many projection profiles and how one object may propagate through one or several of them.

The first unresolved issue is profile-to-profile interaction.

Given two concrete field/profile apertures, do their actions:
- commute,
- depend on order,
- or make one another inadmissible?

The answer depends on the actual closed recursive profile contracts and which state components each profile acts on.

The generic theory cannot pick this without concrete profiles.
