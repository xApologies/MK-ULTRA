# R80 — ENVIRONMENT PROFILE ADMISSIBILITY

## Acceptance relation

Define:

`F ⊨ Pi_alpha`

when closed recursive engine identity `F` is admissible through environmental profile `Pi_alpha`.

This is not ontological equality.

It means:
the object's projection/lift tower admits a profile-compatible seed/readout under the aperture's declared contract.

Then:

`Adm_E(F) = {Pi_alpha in P(E) | F ⊨ Pi_alpha}`.

For each admissible profile, the actual typed operations are:

`Ops(F,Pi_alpha) = Cap(F) ∩ Perm_E(Pi_alpha)`.

---

# Key closure

The environment can contain several profiles simultaneously.

An object can be:
- admissible through one;
- inadmissible through another;
- admissible through several with different dimensional readouts.

Therefore a field/profile does not determine the object's identity.
It determines one **admissible expression channel** of that identity.

Rainbow Road routes only over profile-compatible typed operations.
