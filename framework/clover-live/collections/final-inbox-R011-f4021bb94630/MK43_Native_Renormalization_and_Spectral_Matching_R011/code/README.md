# Reproduction Code

- `spectral_matching.py` computes Schur complements and hard/smooth thresholds.
- `parameter_rank.py` computes parameter-map rank and readable relation bases.
- `functional_determinant.py` computes the finite one-loop determinant and background derivative.

The R010 and R007 matrices are finite formal surrogates. They are not physical Standard Model threshold data.
