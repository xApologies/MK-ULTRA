# Cradle Boundary and Chromatic Readout

Canonical foundational notation:

    0 = DNE
    𝔠 := 0 | 0.

The boundary `|` can relate realized chromatic contributions.

Examples:

    ❤️ | 💛 := 🧡
    💜 | 💚 := 💙

Using toy basin weights:

    R=1, O=2, Y=3, G=4, B=5, V=6,

we obtain:

    (1+3)/2=2 -> Orange
    (6+4)/2=5 -> Blue.

The resolved color is not identical to the exact boundary History. Same readout does not imply same provenance.

Representative seed display:

    ◾️ 🧡
    💙 ◾️

where `◾️` denotes Void/unoccupied addresses and the realized Orange/Blue loci retain their boundary histories.
