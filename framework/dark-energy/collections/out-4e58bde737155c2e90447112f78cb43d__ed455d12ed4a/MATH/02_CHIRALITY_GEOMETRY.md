# Chirality Geometry

## Tile
One address/position in a declared chirality domain. A tile is realized/occupied or Void/DNE.

## Seed
Native `2 x 2` four-address organization.

Working complementary profiles:

    0 1        1 0
    1 0        0 1

The unoccupied `0` locations are interpreted in the current ontology as Void/DNE addresses, not ordinary chromatic zero values.

## Chirality byte
Canonical term: **chirality byte**.

A `2 x 2 x 2` local three-dimensional domain with eight tile addresses. The exact canonical seed-to-byte set-lift remains open.

## Chirality block
Native shared `4 x 4 x 4` domain:

    |B|=64.

Current half-occupancy working profile:

    |E|=32, |V|=32.

The block may be organizationally decomposed as `2 x 2 x 2` chirality bytes while remaining a native shared `4^3` tile domain.

## Chirality fabric
Recursive weave/extension of native blocks. Coordinates are charts, not tile identity. There is no privileged spatial center.
