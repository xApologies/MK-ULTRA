# Resolution Operator

For a declared domain \(D\) and requested readout Resolution \(R\),

\[
\boxed{
\mathfrak R_D^{(R)}:\mathcal X_D\rightharpoonup\mathcal Y_D.
}
\]

It maps exact realized lower-level organization to a domain-level readout while preserving lower-level configuration and History upstream.

Hard firewall:

\[
\boxed{
\mathfrak R_D(X)=\mathfrak R_D(X')
\not\Rightarrow
X=X'.
}
\]

Resolution is not selection:

\[
\boxed{\mathfrak R_D\neq\operatorname{Select}.}
\]

Resolution is not the native update law:

\[
\boxed{\mathfrak R_D\neq U_\chi.}
\]

## Readout composition

For nested/coarsened readouts,

\[
q_{R_2}=q_{R_2R_1}\circ q_{R_1}
\]

whenever \(R_2\) is genuinely a lawful coarsening of \(R_1\).

The native shared-Resolution object is richer than any one coarse Rainbow color.
