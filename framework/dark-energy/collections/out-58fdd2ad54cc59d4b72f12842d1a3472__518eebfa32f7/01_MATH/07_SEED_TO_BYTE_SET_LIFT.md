# Seed → Chirality Byte Set-Lift

Let the abstract seed geometry be the square graph \(Q_2\).

Let occupancy be

\[
o:V(Q_2)\to\{0,1\}.
\]

Define the byte geometry

\[
\boxed{Q_3=Q_2\square K_2.}
\]

Define complementary occupancy

\[
\boxed{
\widetilde o(v,\varepsilon)=o(v)\oplus\varepsilon,
\qquad \varepsilon\in\{0,1\}.
}
\]

Consequences:
- two occupied seed addresses lift to four occupied byte addresses;
- two Void seed addresses lift to four Void byte addresses;
- every elementary cube edge crosses the realized/Void parity partition;
- no privileged global lift axis is required;
- "layer 0/layer 1" is one chart presentation, not ontology.

The lift is therefore combinatorially/geometrically closed.
