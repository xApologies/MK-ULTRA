# Joint Events

Let \(C\) be a finite connected support region in the operative adjacency/dependency graph.

Let

\[
\mathcal X_C\subseteq\prod_{v\in C}X_v
\]

be the constrained joint configuration domain.

A native joint event is a coordinated path

\[
\boxed{
J_C=[\Gamma_C],\qquad
\Gamma_C:[0,1]\to\mathcal X_C.
}
\]

For \(k\) components,

\[
\Gamma_C(s)=(\gamma_1(s),\ldots,\gamma_k(s)).
\]

The parameter \(s\) is an event/path parameter, not necessarily physical time.

Taxonomy:
- independent event: support factorizes;
- ordered coupled event: valid intermediate states exist and order changes context;
- joint event: one non-factorized coordinated path;
- inadmissible: no valid path.

History records one joint event while retaining the internal joint-path witness.

Joint-event semantics are structurally closed.
