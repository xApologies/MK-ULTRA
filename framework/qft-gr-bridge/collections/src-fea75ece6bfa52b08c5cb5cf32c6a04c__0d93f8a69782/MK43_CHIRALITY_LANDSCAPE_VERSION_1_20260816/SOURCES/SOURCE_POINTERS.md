# Source Pointers / Omitted Large Files

The checkpoint includes hashes for all source files visible in the active runtime. Large source packages not duplicated into this version remain independently recoverable by filename + SHA-256.

Especially important:

- `MK Ultra(2).pdf` — full 987-page Tome.
- `BRIDGE(6).zip` — full Admiral's Rosetta Bridge evidence package; a compact core extract is included under `SOURCES/BRIDGE_CORE/`.

See `SOURCE_MANIFEST.json` and `SOURCE_HASHES.sha256`.
