# E067 — Metric-Variation Kernel Factorization

Let `S_H^cov(Q_H,g)` be the already-defined covariant hidden action family and define

`V_g(S_H) := -(2/sqrt(-g)) δS_H/δg^(μν)`.

The hidden stress-energy family is the image of this map on admitted hidden actions. Define

`Ker(V_g) := { S_H in S_H^cov | V_g(S_H)=0 }`

and the stress-active fiber

`S_H,act^cov := S_H^cov \\ Ker(V_g)`.

Then

`S_H,act^cov != empty`

is equivalent to the existence of at least one admitted covariant hidden action generating nonzero hidden stress-energy.

This does not solve physical action selection. It proves that **unique selection is stronger than the immediate internal existence question requires**.
