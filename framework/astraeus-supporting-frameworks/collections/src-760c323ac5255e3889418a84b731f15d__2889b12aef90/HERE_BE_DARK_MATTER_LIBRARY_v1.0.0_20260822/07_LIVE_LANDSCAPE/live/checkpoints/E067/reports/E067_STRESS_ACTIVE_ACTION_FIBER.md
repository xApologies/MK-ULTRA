# Astraeus Dark Matter — E067 Stress-Active Action Fiber

The metric-action blocker was stronger than the current existence problem required.

DM 2.2 asks which member/equivalence class of the covariant hidden action family is physically realized. For internal nonemptiness scouting, that is overkill. The immediate question is whether **any** admitted covariant hidden action has nonzero metric variation.

E067 therefore factors the action family by the kernel of metric variation and creates the live object `@dm_stress_active_action_fiber`.

The new frontier is

`@dm_stress_active_action_fiber_nonempty`.

If this set is empty, the covariant action branch cannot supply hidden stress-energy. If nonempty, a nonzero hidden stress-energy member exists without yet solving unique physical action selection.
