# V36 — Projection / Residue Survival Test

## Status

NEW DERIVED TEST ARCHITECTURE.

## Matched full / visible comparison

Take two Resolution-R constructions under the same declared external
comparison conditions:

    N_full^R
    =
    visible organization + hidden S3 organization

and

    N_vis^R
    =
    visible-only organization.

Assume each admits at least one boundary realization through R_HdXi^R.

Let the resulting projection-residue bundle triples be

    B_full^R
    =
    (
      M_full,
      F_full,
      pi_full
    )

and

    B_vis^R
    =
    (
      M_vis,
      F_vis,
      pi_vis
    ).

## Declared bundle equivalence

Use the ordinary notion of smooth bundle isomorphism, strengthened by the
requirement that the selected invariant-residue data used by the
Resolution-R comparison are preserved.

Write

    B_full^R ~=_F B_vis^R

when such an isomorphism exists.

The exact inventory of compared residue invariants must be declared by
the experiment/model; v36 does not invent it.

## Sufficient survival witness

If

    B_full^R
    not ~=_F
    B_vis^R,

then the hidden-network distinction has survived at least to the
projection-residue bundle level.

This is a sufficient witness of field-bundle-level distinguishability.

## Why the converse is not asserted

If

    B_full^R ~=_F B_vis^R,

the hidden distinction may still survive in later data that do not alter
the underlying bundle isomorphism class, for example:

- a field section;
- connection data;
- curvature;
- observable algebra;
- spectral data;
- other components of the canonical Q handoff.

Therefore bundle equivalence does not prove complete erasure.

## Dark-matter boundary

Even

    B_full^R not ~=_F B_vis^R

does not yet establish dark matter.

A successful dark-source route still requires a typed path from the
surviving field / handoff distinction to a stress-energy distinction and
then to the gravitational readout.

## Failure logic

A residue route is ruled out for a particular hidden state if:

1. R_HdXi^R has empty fiber for that state; or
2. every admitted boundary realization is erased by projection and all
   later Q-handoff data remain equivalent to the visible-only case.

The second condition requires the full Q-handoff comparison; bundle
isomorphism alone is not enough.
