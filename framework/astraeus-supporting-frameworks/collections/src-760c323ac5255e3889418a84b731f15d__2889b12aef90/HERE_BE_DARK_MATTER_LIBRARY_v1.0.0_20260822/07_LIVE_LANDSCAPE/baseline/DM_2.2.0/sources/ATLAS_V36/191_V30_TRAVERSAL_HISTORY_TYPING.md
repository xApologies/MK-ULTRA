# V30 — Stateful Traversal Typing of the S3 History Support

## Recovered Traversal Operator

A traversal state is

```text
X_k = (v_k,d_k,H_k,sigma_k)
```

and repeated traversal is

```text
X_k = P^k(X_0).
```

The full traversal

```text
Gamma_n = (X_0,...,X_n)
```

retains node position, depth, inherited dependency closure, and active context.

Two traversals at the same node may produce different successors when `H_k` or `sigma_k` differs. History dependence is therefore native to the operator.

## Refined v25 support set

For an S3 relation `e`, replace an untyped history label with the stateful set

```text
Hist_R(e)
=
{
  Gamma_n :
  Gamma_n is generated by P under declared Resolution R,
  e is traversed by Gamma_n,
  required identity/chirality/persistence/closure conditions survive
}.
```

This supplies explicit provenance for the previously defined history-agreement support.

## Energy-labelled history spectrum

Because Native History Energy is defined on ordered histories, define the set-valued diagnostic

```text
Spec_E^R(e)
=
{ Energy_MK(Gamma) : Gamma in Hist_R(e) }.
```

No summation, density, or edge capacity is inferred from this spectrum.

It merely records which native history-energy values occur among admissible traversals supporting relation `e`.

## Remaining question

The sources still do not supply a canonical map

```text
Hist_R(e) -> k_e
```

or

```text
Spec_E^R(e) -> T_run(e).
```

Those remain constitutive targets rather than definitions.
