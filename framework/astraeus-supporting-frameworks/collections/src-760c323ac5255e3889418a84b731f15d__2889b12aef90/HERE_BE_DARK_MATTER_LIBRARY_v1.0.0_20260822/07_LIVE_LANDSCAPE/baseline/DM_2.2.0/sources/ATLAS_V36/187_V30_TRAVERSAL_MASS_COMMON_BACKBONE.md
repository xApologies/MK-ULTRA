```text

I_k(u) R_k(u) B_k(u) O_k(u) C_k(u)
```

## Shared backbone

Define only as a bookkeeping abbreviation

```text
Q_k(u) = I_k(u) R_k(u) B_k(u) O_k(u)
```

and, at recursive depth d,

```text
Q_d([X]) = Inh_d([X]) Band_d([X]) Res_d([X]) Occ_d([X]).
```

Then the two source structures have the form

```text
Traversal selection:   Phi ~ Q * OrientationCompatibility
Locked persistence:    Pers_d = Q * ClosureRetention
```

The domains and normalizations are not asserted identical. The point is structural ancestry: four organizational roles recur, while the fifth role changes from pathwise orientation admissibility to retained closure.

## No-go

It is invalid to identify

```text
Phi_k == Pers_d
```

or to infer Native Mass directly from a traversal score.

A bridge is required between successful orientation-admissible traversal and closure retention.

Define that missing typed target schematically as

```text
K_OC : admissible traversal organization -> closure-retention organization.
```

No numerical formula for `K_OC` is supplied in the recovered sources.
