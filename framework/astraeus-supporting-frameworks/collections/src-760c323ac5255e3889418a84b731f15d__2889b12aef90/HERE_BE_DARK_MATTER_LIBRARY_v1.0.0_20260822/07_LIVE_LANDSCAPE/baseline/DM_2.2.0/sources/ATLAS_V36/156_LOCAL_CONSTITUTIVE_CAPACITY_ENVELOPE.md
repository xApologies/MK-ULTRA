# 156 — Local Constitutive Capacity Envelope

## Status

Derived mathematics, conditional on the recovered ER-flow relation.

This file does **not** introduce a new dark-matter field or new physical substance.
It closes one mathematical question left open by Atlas v20: how a finite local
upper bound on runtime continuity flow can arise from already-existing Time-Space
objects.

## Recovered input law

The Time-Shell / ER-foam recovery preserves the relation

```text
Phi_ij = kappa_ij A_ij (C_j - C_i)
```

where:

```text
Phi_ij   = continuity flow on directed relation i -> j
kappa_ij = local continuity-response coefficient in this recovered law
A_ij     = admissibility factor for the relation
C_i,C_j  = endpoint continuity states
```

The same relation occurs in an earlier technical working scaffold. Because that
earlier source explicitly labeled its scaffold non-final, this Atlas release treats
the relation as a **recovered constitutive candidate/library-preserved relation**,
not as a universally proved native law.

No identification `kappa_ij = k_ij` is made here unless a later source proves it.

## Feasible endpoint set

Let `F_run(G_*)` be the v20 globally feasible runtime-flow family on the selected
persistent support `G_*=(V_*,E_*)`.

For an edge `e_ij`, define its feasible endpoint-continuity set

```text
D_ij
=
{(C_i,C_j) : the pair occurs in at least one globally feasible runtime state}.
```

The set `D_ij` therefore already inherits all active constraints:

- admissibility,
- chirality compatibility,
- Bandwidth,
- R5 ordered topology resolution,
- ancestry/recoverability,
- R6 survivability,
- R7 persistence,
- boundary conditions,
- and continuity conservation.

## Positive drive bound

For directed flow `i -> j`, define

```text
DeltaC_ij^+
=
sup_{(C_i,C_j) in D_ij} max(0, C_j - C_i).
```

For magnitude-only use, define

```text
DeltaC_ij^abs
=
sup_{(C_i,C_j) in D_ij} |C_j - C_i|.
```

If the feasible continuity states are bounded, these quantities are finite.
If `D_ij` is compact, the extrema are attained.

## Local capacity envelope

Assume on the active admissible branch

```text
kappa_ij >= 0
A_ij >= 0.
```

Define the directed local envelope

```text
U_ij^+
=
kappa_ij A_ij DeltaC_ij^+.
```

and the magnitude envelope

```text
U_ij^abs
=
kappa_ij A_ij DeltaC_ij^abs.
```

Then every feasible flow satisfying the recovered constitutive relation obeys

```text
Phi_ij <= U_ij^+
```

and

```text
|Phi_ij| <= U_ij^abs.
```

Therefore the v20 runtime Transition Capacity satisfies

```text
T_run(e_ij) <= U_ij^+.
```

This is an **upper envelope**, not automatically the realized capacity.
Global conservation, shared Bandwidth, competing corridors, ancestry, and R5/R6
constraints may prevent the locally extremal endpoint state from being realized
inside a globally feasible flow.

## Explicit interval specialization

If the local feasible endpoint set is the full rectangle

```text
C_i in [C_i^-, C_i^+]
C_j in [C_j^-, C_j^+],
```

then

```text
DeltaC_ij^+
=
max(0, C_j^+ - C_i^-)
```

and

```text
DeltaC_ij^abs
=
max(|C_j^+ - C_i^-|, |C_i^+ - C_j^-|).
```

Thus

```text
T_run(e_ij)
<=
kappa_ij A_ij max(0, C_j^+ - C_i^-).
```

## Global bounded-continuity specialization

If a region satisfies

```text
C_min <= C(x) <= C_max
```

for every admissible site, then

```text
T_run(e_ij)
<=
kappa_ij A_ij (C_max - C_min).
```

No assumption `C_min = 0` is made.

## Interpretation

The v20 capacity object is not an arbitrary new amplitude.
The recovered flow relation shows how a local capacity bound can be generated by:

```text
admissibility gate
x
continuity response
x
finite admissible continuity drive.
```

Bandwidth, chirality, strain, and recoverability are not multiplied into this
formula by hand. They constrain `D_ij` and the global feasible-flow family.
