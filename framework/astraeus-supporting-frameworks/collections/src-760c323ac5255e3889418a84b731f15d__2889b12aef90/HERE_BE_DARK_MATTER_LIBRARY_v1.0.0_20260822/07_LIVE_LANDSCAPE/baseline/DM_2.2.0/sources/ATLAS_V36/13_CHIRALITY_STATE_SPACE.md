# 13 — Chirality State Space

## Purpose

Atlas v2.0 needs a chirality object that is large enough to carry the existing seed/cube/history machinery without prematurely choosing a conventional gauge group.

The construction below therefore begins from the already-available Bandwidth Algebra and defines the chirality fiber from admissible transformations rather than inserting `U(1)`, `SU(2)`, `SU(3)`, or another external group by name.

---

## 13.1 Chirality transformation sector

Let `A_B` be the Transduction Geometry Bandwidth Algebra at Bandwidth `B`.

Define the chirality-typed transformation sector:

```text
A_B^chi subset A_B
```

as the typed subalgebra/partial algebra generated by transformations whose declared domain and codomain are chirality-bearing states and whose action preserves the applicable chirality admissibility contract.

This construction deliberately allows noninvertible transformations.

---

## 13.2 Seed carrier

Let `C_seed` denote a source-authoritative chirality seed representation. The existing project representations include the left/right seed, serialized chirality byte, and 2x2x2 occupancy cube. These are representations of chirality organization and are not silently identified with the full chirality state space.

Define the Bandwidth-accessible chirality orbit:

```text
Omega_chi(B)
:=
{ a(C_seed) | a in A_B^chi and a(C_seed) is typed/admissible } / ~_chi
```

where `~_chi` is the declared chirality equivalence relation preserving the selected invariant organization.

`Omega_chi(B)` is the candidate typical chirality fiber.

The construction has two advantages:

1. it grows only by admitted MK43 transformations;
2. it does not force the foundational chirality object to be only binary.

The left/right states remain distinguished elements/classes inside `Omega_chi(B)`.

---

## 13.3 Reversible transport subgroup

Transport and transduction are not identical.

Define the reversible/unit sector:

```text
G_chi(B) := Units(A_B^chi)
```

consisting of chirality transformations that possess admissible typed inverses inside the selected scope.

`G_chi(B)` acts on `Omega_chi(B)`.

The mirror operator `M_chi`, when admitted in the selected scope, satisfies:

```text
M_chi^2 = id
```

and therefore belongs to the reversible sector.

Noninvertible chirality transformations remain valid transductions but are not used as reversible parallel transport maps.

---

## 13.4 Chirality carrier over Time-Space

Let:

```text
pi_chi : E_chi -> T5
```

be a chirality carrier whose local typical fiber is `Omega_chi(B)`.

For each localized spacetime projection:

```text
Sigma_p := pi^(-1)(p) ~= S2,
```

define the admissible local chirality configuration space:

```text
C_p(B,R)
:=
Gamma_adm(E_chi | Sigma_p) / ~_R.
```

Here:

- `Gamma_adm` selects admissible sections;
- Bandwidth determines which transformations are operative;
- Resolution `R` identifies distinctions that are observationally unreadable.

The formal, pre-Resolution section space is:

```text
C_p^formal(B) := Gamma_adm(E_chi | Sigma_p).
```

---

## 13.5 Four objects that must remain distinct

Atlas v2.0 freezes the following distinction:

```text
chirality state     != chirality fiber
chirality fiber     != chirality field/section
chirality section   != chirality history
chirality history   != serialized byte/cube representation
```

A local field may change representation while its Identity Witness remains recoverable.
