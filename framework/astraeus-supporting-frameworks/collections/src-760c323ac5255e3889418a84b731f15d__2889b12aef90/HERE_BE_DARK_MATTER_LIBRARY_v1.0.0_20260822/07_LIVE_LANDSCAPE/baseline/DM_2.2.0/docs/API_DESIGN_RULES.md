# Dark Matter API 2.0 Design Rules

## Simple

Keep the direct graph small and typed.

## Elegant

Use one object for one mathematical role. Split overloaded handles.

## Sophisticated

Let recursive dependency closure compute consequences, but keep those
consequences distinct from primitive/source-backed edges until promoted by
a targeted proof or recovery pass.

## Failure discipline

- Circular definitions are removed or factored.
- Local no-go theorems prune only their exact mechanism.
- Quarantined branches are not crawled.
- Open maps become handles rather than prose holes.
- Composed dependencies are not automatically physical mechanisms.
