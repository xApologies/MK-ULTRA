# 27 — Bianchi / Source-Exchange Closure

## Required local GR condition

```text
nabla^m G_mn = 0.
```

If

```text
G_mn = 8*pi*G (T_mn^vis + T_mn^H),
```

then consistency requires

```text
nabla^m(T_mn^vis + T_mn^H) = 0.
```

## Sector exchange current

The individual sectors need not be separately conserved if energy/momentum/continuity is transduced between them. Define a local exchange current

```text
J_n^H
=
nabla^m T_mn^vis
=
- nabla^m T_mn^H.
```

Then

```text
nabla^m(T_mn^vis + T_mn^H)=0
```

holds identically.

## Decoupled stationary regime

If

```text

```

then

```text
nabla^m T_mn^vis = 0
nabla^m T_mn^H   = 0.
```

This is the simplest halo-like regime.

## Transduction interpretation

The exchange current is the local GR accounting image of a deeper transduction across representations. It is not evidence that energetic content disappears from one sector.
