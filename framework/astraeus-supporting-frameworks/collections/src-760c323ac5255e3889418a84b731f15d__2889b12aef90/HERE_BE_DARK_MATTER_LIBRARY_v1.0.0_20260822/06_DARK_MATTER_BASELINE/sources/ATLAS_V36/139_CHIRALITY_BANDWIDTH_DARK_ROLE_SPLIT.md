# 139 — Chirality / Bandwidth / Dark-Readout Role Split

## Source-grounded correction

The recovered R4-R6 architecture makes an important distinction explicit:

```text
Chirality is read-only.
Bandwidth occupancy is finite.
Corridor topology is selected under chirality, Bandwidth, strain, recoverability, and ancestry.
```

Therefore V18 does not identify chirality with dark matter or with native energy.

## Role split

### Chirality

Chirality constrains:

```text
orientation
alignment
admissible directionality
corridor compatibility
ancestry-preserving topology.
```

It helps determine **which relationships can exist**.

### Bandwidth

Bandwidth constrains:

```text
how much recoverable corridor occupation is supportable
which transformations remain available
when topology becomes overoccupied / unrecoverable.
```

It helps determine **how much relational transition capacity can remain active**.

### Resolution

Resolution determines which distinctions in that organized state remain readable in a selected projection.

### Dark readout

V15 defined darkness through failure of ordinary matter readout to factor the gravitational readout.

V18 preserves that definition:

```text
matter readout can conflate states
gravity can still distinguish them.
```

## Native energy insertion after topology selection

Let `E_H^*` be the R4-R7 selected persistent corridor support.

For each surviving relation `e`, let

```text
r_e = Relationship valuation
t_e = Resolution-qualified Bandwidth-supported Transition Capacity.
```

Then the v17 additive finite realization becomes

```text
rho_E,H^R(i)
=
SUM_{e incident on i, e in E_H^*} r_e t_e
/
nu_R(i).
```

The ordering is therefore:

```text
chirality + adjacency + strain
-> R4 possibilities
-> Bandwidth/recoverability-constrained R5 topology
-> R6/R7 persistent corridor support
-> Relationship x TransitionCapacity energetic ledger
-> UCM source projection
-> gravity.
```

## Consequence

This supports the working interpretation:

```text
chirality explains organization of the hidden geometry;
Bandwidth helps determine the supported transition load;
Resolution helps determine why some of that organization is dark to ordinary readout;
gravity reads the surviving UCM load downstream.
```

It does not prove that this load is astrophysical dark matter.
