# 06 — Local QFT / GR Bridge Through Chirality

## Local common parent

For a selected localized spacetime projection `Sigma_p`:

```text
chi_p -> Phi_p := rho_Q,p(chi_p)
chi_p -> g_p   := rho_G,p(chi_p).
```

The bridge is therefore local to the same `S2` projection:

```text
QFT_p <- chi_p -> GR_p.
```

## Einstein-compatibility target

Let:

```text
g_mn^(p) = rho_G,p(chi_p)
Phi_p    = rho_Q,p(chi_p).
```

Then the compatibility target is:

```text
G_mn[rho_G,p(chi_p)]
=
8 pi G T_mn[rho_Q,p(chi_p), rho_G,p(chi_p)].
```

The equation is a closure/compatibility statement between two representations of common local ancestry.

## Sector intertwining target

For transport from `p_alpha` to `p_beta`:

```text
rho_Q,beta o P_gamma^chi
=
U_Q(gamma) o rho_Q,alpha
```

and:

```text
rho_G,beta o P_gamma^chi
=
U_G(gamma) o rho_G,alpha.
```

These equations are the natural global consistency conditions for a one-landscape model.
