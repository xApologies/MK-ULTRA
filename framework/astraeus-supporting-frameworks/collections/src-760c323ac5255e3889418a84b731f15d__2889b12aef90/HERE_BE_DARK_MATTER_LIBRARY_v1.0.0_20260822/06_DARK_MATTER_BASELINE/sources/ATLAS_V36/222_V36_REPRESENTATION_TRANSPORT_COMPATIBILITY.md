## Recovered native transport

The current Time-Space foundation contains Chirality Transport

    tau : Omega -> Omega

with inheritance compatibility

    chi(I(xi))

## Downstream transport requirement

A chromatic/basin representation used along an inherited history requires
a corresponding downstream transport law if represented states are to be
compared dynamically.

Let

    tau_C : X_C^R -> X_C^R

be such a transport, if one is recovered or lawfully derived.

No universal tau_C is asserted in v36.

## Relational equivariance criterion

The representation relation R_OmegaC^R is transport-compatible when

    (omega,z) in R_OmegaC^R

implies

    (tau(omega), tau_C(z))
    in
    R_OmegaC^R.

By induction, if the criterion holds repeatedly,

    (omega,z) in R_OmegaC^R

implies

    (tau^n(omega), tau_C^n(z))
    in
    R_OmegaC^R

for every admitted finite n.

## Functional special case

If the relation is the graph of a function

    r_OmegaC^R : Omega -> X_C^R,

then transport compatibility becomes the commuting condition

    r_OmegaC^R o tau
    =
    tau_C o r_OmegaC^R.

## Consequence for corridor work

The current corridor mathematics transports chirality coherently through
tau.

A downstream chromatic/basin corridor representation is therefore not
licensed merely by assigning a color/basin state at the source.

It must either:

1. possess a typed transport satisfying the criterion above; or
2. remain a static endpoint representation with no claim of transported
   chromatic identity.
