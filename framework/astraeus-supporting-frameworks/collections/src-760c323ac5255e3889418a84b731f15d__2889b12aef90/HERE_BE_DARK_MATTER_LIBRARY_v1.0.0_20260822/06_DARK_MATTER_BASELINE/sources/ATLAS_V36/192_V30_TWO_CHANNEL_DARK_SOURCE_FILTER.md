# V30 — Two-Channel Dark-Source Filter

## Starting point

V29 established a positive hidden native relationship/capacity load under declared assumptions:

```text
Delta rho_H > 0.
```

V30 now prevents that result from being silently renamed Mass.

## Channel M — lock/Mass channel

A hidden organization may enter this branch only if bounded T4 Mass admission succeeds:

```text
hidden S3 organization
-> Mass-admissible bounded T4 closure
-> P4_lock
-> Delta Pers_lock
-> Delta Mass_MK
-> readable gravitational-Mass correspondence target.
```

For a relational composite, the relevant scalar may be `DeltaMass_N`.

## Channel E — non-Mass native-load channel

A hidden organization may instead carry relationship/capacity load without changing a T4 lock:

```text
hidden S3 relationship/capacity
-> Delta rho_H > 0
-> native energy/UCM source transduction
-> T_mn
-> gravity.
```

This channel remains open at the `native load -> T_mn` map.

## Separator

For two Mass-admissible comparison states with the same declared visible reference, define

```text
Delta M_H
=
Mass_MK([X_full]) - Mass_MK([X_vis]).
```

Then:

```text
Delta M_H != 0
```

means hidden organization has entered the Native Mass channel.

If instead

```text
Delta M_H = 0
and
Delta rho_H > 0,
```

any surviving gravitational residual must use the non-Mass load channel, unless another source mechanism is separately derived.

## No double counting

Until an explicit dictionary proves overlap, Channel M and Channel E are tracked separately.

A lock-formation history may connect them in the special case already proved by the Mass formalism, but that identity is not generalized to arbitrary hidden load.
