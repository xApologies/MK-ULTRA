# 85 — Persistence and Time-Shell Translation Order

## Recovered ordering correction

The Transduction Geometry live branch repeatedly distinguishes:

```text
local-to-global gluing / Identity recovery
        BEFORE
Time-Shell translation
        BEFORE
projection/readout.
```

Therefore:

```text
Time Shell != cause of persistence.
```

The strongest current order is:

```text
STAGE 1 — local coherence
STAGE 2 — global persistence / Identity recovery
STAGE 3 — shell translation / external readability
STAGE 4 — channel-specific projection
STAGE 5 — Resolution-bounded readout.
```

## Resolution-Bandwidth condition

A persistent translation boundary is distinguished from a generic boundary by sufficient stabilization of Resolution/Bandwidth around the transition.

This allows local shell patches to have:

```text
R_i != R_j
B_i != B_j
```

while still belonging to one globally persistent Identity class, provided inherited compatibility closes.

## Consequence

Persistence quality and translation fidelity are separate quantities.

A structure may remain itself internally while being poorly readable externally.
