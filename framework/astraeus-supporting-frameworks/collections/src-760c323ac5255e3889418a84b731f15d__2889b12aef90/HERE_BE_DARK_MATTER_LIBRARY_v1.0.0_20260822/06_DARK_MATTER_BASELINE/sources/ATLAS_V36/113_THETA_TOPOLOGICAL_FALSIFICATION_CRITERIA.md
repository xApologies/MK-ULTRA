# 113 — Topological Falsification Criteria for Theta_ER->S3

## Purpose

The ER-to-S3 translation must be easy to kill if it is wrong.

V13 therefore freezes mathematical failure conditions before numerical astronomy is consulted.

---

## Test 1 — Global nerve topology

If the relevant admissible continuity cover is a good cover of the whole `S3`, then

```text
|N_R| ~=_h S3.
```

Therefore its homology must agree with `S3`:

```text
H_0 ~= Z
H_1 = 0
H_2 = 0
H_3 ~= Z
```

with all higher groups zero in the ordinary singular-homology chart.

### Failure condition

If the completed higher-order ER continuity complex retains robust global `H_1` or `H_2` classes at the Resolution where the good-cover claim is made, then at least one of the following is false:

```text
the complex is complete;
the cover is good;
the translated region is all of S3;
the S3 assignment is correct.
```

Do not hide the mismatch with extra parameters.

---

## Test 2 — Graph-only insufficiency

A pairwise graph with large cycle rank does **not** by itself contradict S3. The relevant question is whether higher-order closure simplices fill those cycles in the enriched complex.

### Failure condition

If no source-grounded higher-order closure relation can supply the simplices required by the claimed nerve topology, direct global `Theta_ER->S3` fails.

---

## Test 3 — Corridor composition

For every composable recovered ER route `q2 o q1`, require

```text
F_Theta(q2 o q1)
~=
F_Theta(q2) * F_Theta(q1).
```

### Failure condition

A systematic composition mismatch is a translation failure, not “new physics.”

---

## Test 4 — Chirality compatibility

Require

```text
P^chi_(F_Theta(q))(chi_source)
~=
chi_target.
```

### Failure condition

A route that repeatedly violates recovered chirality inheritance is inadmissible.

---

## Test 5 — Identity / invariant residue

Require translated paths to preserve recoverable identity and declared invariant residue according to corridor rules.

### Failure condition

If the translation preserves adjacency but destroys identity ancestry, it is not an admissible Atlas translation.

---

## Test 6 — Resolution refinement

For `R' > R`, a valid translation family should admit compatible coarse readout:

```text
N_R' -> N_R
```

without changing the declared large-scale continuity identity arbitrarily.

### Failure condition

If small changes in Resolution force unrelated global topology with no controlled quotient/refinement relation, the translation lacks recursive continuity.

---

## Test 7 — Black-hole mark stability

The recovered black-hole invariant must remain identifiable under translation/refinement.

### Failure condition

If the marked hub disappears merely because the representation changes, the proposed BH/S3 address map fails the Identity-Through-History criterion.

---

## V13 Watcher rule

`Theta_ER->S3` is not promoted because it is elegant.

It survives only if the recovered ER organization can satisfy these tests without retrofitting.
