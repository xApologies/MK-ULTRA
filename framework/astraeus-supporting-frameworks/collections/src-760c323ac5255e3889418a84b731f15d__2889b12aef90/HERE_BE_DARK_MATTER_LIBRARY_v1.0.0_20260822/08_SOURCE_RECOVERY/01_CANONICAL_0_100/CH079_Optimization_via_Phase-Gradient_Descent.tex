\chapter{Optimization via Phase-Gradient Descent}

\section{General Optimization Law}
Optimization variable evolves by:
\[
\partial_t x^i = -\mu\,\partial^i\tau_{\mathrm{opt}}.
\]

\section{Global Minimum Condition}
Minimum occurs when:
\[
\partial_i \tau_{\mathrm{opt}} = 0.
\]
