\chapter{Ethical Phase Gradients and Moral Field Dynamics}

\section{Moral Phase Field}
Define a moral field:
\[
\tau_{\mathrm{moral}} = \sum_i w_i M_i,
\]
where \(M_i\) represents localized ethical weight.

\section{Ethical Gradient Flow}
Moral drift evolves by:
\[
\partial_t M = -\alpha\,\partial\tau_{\mathrm{moral}}.
\]
