\chapter{Phase-Driven Stellar Evolution and End States}

\section{Phase Gradient Evolution}
The stellar phase field evolves with radius:
\[
\tau_\star(r) = \tau_c - \kappa r^2.
\]

\section{White-State Thresholds}
Collapse threshold:
\[
(\partial\tau)^2 > \tau_{\mathrm{crit}}.
\]
