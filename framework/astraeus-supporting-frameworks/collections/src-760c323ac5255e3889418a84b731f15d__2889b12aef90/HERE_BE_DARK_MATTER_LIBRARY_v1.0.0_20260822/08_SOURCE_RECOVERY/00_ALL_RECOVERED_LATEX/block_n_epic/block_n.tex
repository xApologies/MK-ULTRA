Fractal civilizations and meta-civilizations now scale into cosmic structures.  
Their interactions form networks so vast and coherent that they produce the first  
Abyssalum-wide intelligence: the \emph{Constellate}.  
Civilizations become luminous nodes in a galactic cognitive architecture.

\section{Meta-Civilizational Signatures}
A meta-civilization $\mathbb{X}$ has its own spectral signature:
\[
\Sigma_{\mathbb{X}} = R(\mathbb{X}),
\]

encoding merged world-signatures, alliance invariants, treaty manifolds, attractors,
and recursive governance harmonics.

Compatibility is measured by:
\[
d(\mathbb{X}_A,\mathbb{X}_B)
=
\big\| \Sigma_{\mathbb{X}_A} - \Sigma_{\mathbb{X}_B} \big\|.
\]
