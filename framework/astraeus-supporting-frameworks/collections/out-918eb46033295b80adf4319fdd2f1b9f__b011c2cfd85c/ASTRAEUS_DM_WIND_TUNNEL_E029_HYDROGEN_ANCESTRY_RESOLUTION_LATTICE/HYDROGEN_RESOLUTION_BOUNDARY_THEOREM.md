# Hydrogen Anchor Resolution Boundary — Work-Layer Theorem

Let `H` be the fixed Hydrogen anchor with parent feature set `C_H`.

Let `F0` and `F1` be the fresh-history and H2-conditioned operative states.

Assume the source-backed experimental facts:

1. the Hydrogen parent factor `X_H` is identical in both states;
2. the four contextual environment/History fields in `E_H` differ;
3. Resolution access is modeled by feature-subset inclusion without inventing new
   ancestry.

Then:

### Intrinsic equality

For every intrinsic Resolution node:

`S subseteq C_H`,

the Hydrogen-readable presentations agree:

`Read_S(F0) = Read_S(F1)`.

### Contextual emergence

For every extended node:

`S subseteq C_H union E_H`,

if:

`S intersect E_H != empty`,

then the pair is distinguishable in the current exact-array readout model.

### Coarsening collapse

If all environmental History features are forgotten:

`S intersect E_H = empty`,

the distinction collapses back to the fixed Hydrogen anchor.

Thus the current pair's hidden distinction is **contextual/History-bearing rather than
intrinsic to the mounted Hydrogen parent manifold**.

This theorem is relative to the declared ancestry-access readout family.
It is not a claim that all possible physical measurements obey this binary feature
model.
