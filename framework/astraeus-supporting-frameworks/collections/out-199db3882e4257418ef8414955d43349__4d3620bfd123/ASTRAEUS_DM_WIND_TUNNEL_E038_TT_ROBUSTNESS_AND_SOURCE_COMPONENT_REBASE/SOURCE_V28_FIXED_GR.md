# 180 — Fixed-GR Source Separation Theorem

## Purpose

Once a UCM source difference reaches the conventional Einstein sector, the Atlas needs to know whether that source difference can disappear while the readable metric remains identical.

## 1. Fixed readable gravity problem

Use the same downstream Einstein equation and the same external/background problem data `beta_ext` in both comparisons:

```text
G_mn[g] + Lambda g_mn = kappa T_mn.
```

Let

```text
g_full = Gamma(T_full,beta_ext)

g_vis  = Gamma(T_vis,beta_ext).
```

## 2. V28-T3 — Source separation

Suppose both pairs are solutions of the same readable field equation with the same constants and the same declared external data.

If

```text
g_full = g_vis,
```

then the left-hand sides are identical, so

```text
T_full = T_vis.
```

Contrapositively,

```text
T_full != T_vis
=>
g_full != g_vis.
```

This is the downstream source-separation theorem already implicit in v16-v17, now attached directly to the v28 UCM fiber test.

## 3. Scope

The theorem does not establish that the hidden S3 network produces `T_full != T_vis`.

That is the upstream UCM sensitivity problem in Files 178-179.

It says that **if** a source distinction is successfully produced inside one fixed readable GR problem, it cannot be erased while retaining the identical metric solution.

## 4. Boundary conditions and gauge

"Same metric" here means the same geometric solution modulo the declared gauge/diffeomorphism equivalence and with the same constants/source convention.

Changing external boundary data, cosmological constants, or source conventions invalidates the direct comparison and must be treated as a different problem.

## 5. Combined implication

Under the fixed-GR assumptions:

```text
M_R(u_full)=M_R(u_vis)
+
Pi_U(u_full)!=Pi_U(u_vis)

=>
T_full != T_vis

=>
g_full != g_vis.
```

Thus the unresolved step is sharply localized to the UCM source projection rather than to the downstream Einstein response.
