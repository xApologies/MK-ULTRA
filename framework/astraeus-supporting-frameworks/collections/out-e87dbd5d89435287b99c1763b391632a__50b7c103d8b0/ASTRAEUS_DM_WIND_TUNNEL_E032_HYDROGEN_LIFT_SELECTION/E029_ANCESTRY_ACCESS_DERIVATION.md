# E029 — Hydrogen Ancestry-Access Resolution Lattice

## Why no numerical Resolution scale is introduced

The source only requires `Res` to be an indexing structure.
For monotone scopes, finer Resolution corresponds to a finer congruence.
It also explicitly permits a general Resolution graph.

Therefore E029 does not invent meter-like or energy-like Resolution levels.

Instead, it instantiates the maximal **ancestry-access lattice** generated by the
source-retained parent features of the Hydrogen anchor.

A Resolution node is the set of inherited features presently distinguishable.

Order is set inclusion.

Refinement adds inherited readable features.
Coarsening forgets them.

This directly realizes:

`F_Ri(U_H) subseteq F_Rj(U_H)`

without imposing an arbitrary scalar zoom.

## Intrinsic Hydrogen landscape

The mounted H-v2 parent contains 13 named source channels.

Let:

`C_H = {c_1,...,c_13}`.

Define the intrinsic access landscape:

`Res_H^int := P(C_H)`

ordered by inclusion.

It has:

`2^13 = 8192`

Resolution nodes.

The fresh-history and H2-conditioned experiments use the exact same Hydrogen parent
source factor.

Therefore **every node** in `Res_H^int` presents the same Hydrogen ancestry on both
sides of the pair.

No refinement of Hydrogen's own 13-channel parent organization distinguishes the two
histories.

This is an exact result of the current experiment construction, not a threshold claim.

## Extended contextual landscape

Now adjoin the four endogenous environment/History fields from E003:

`E_H = {chi_history, adjacency_memory, corridor_memory, persistent_memory}`.

Each of these fields differs nontrivially between fresh and H2-conditioned
environments.

Define:

`Res_H^ext := P(C_H union E_H)`.

It has:

`2^17 = 131072`

nodes.

At a node `S`:

- the pair is quantum-/H-anchor equal if `S` contains no environment-History feature;
- the pair is distinguishable if `S` contains at least one environment-History feature.

Counts:

- equal nodes: `2^13 = 8192`;
- distinguishable nodes: `2^17 - 2^13 = 122880`.

## Emergence without arbitrary scale

There is no unique scalar `R_emerge` because the Resolution structure is a partial
order, not a forced line.

The pair distinction has a four-element **minimal emergence antichain**:

- `{env_chirality_history}`
- `{env_adjacency_memory}`
- `{env_corridor_memory}`
- `{env_persistent_memory}`

Along any monotone refinement path, the hidden-history distinction emerges exactly at
the first node where one of these four contextual features becomes readable.

Under coarsening, the distinction dies exactly when the last readable
environment-History feature is forgotten.

This is observational merge/death, not destruction of the underlying History.
