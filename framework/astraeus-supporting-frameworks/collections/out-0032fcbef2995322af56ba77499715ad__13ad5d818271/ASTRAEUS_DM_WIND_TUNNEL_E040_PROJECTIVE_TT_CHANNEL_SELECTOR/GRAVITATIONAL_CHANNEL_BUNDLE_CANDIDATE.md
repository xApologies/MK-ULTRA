# Candidate Gravitational Channel Bundle

For a current precursor `S`, define the projective TT-support base:

`U_TT(S) subset RP^2`.

Over each projective direction `[n]`, attach the currently admissible internal
helicon/chirality mode set:

`M_g(x,[n])`.

Then define the candidate channel bundle:

`pi_g : C_g(x,S) -> U_TT(S)`,

with fiber:

`pi_g^(-1)([n]) = M_g(x,[n])`.

This is a work-layer organizational object, not a promoted physical bundle.

Why it is useful:
- TT geometry supplies the base;
- chirality can supply orientation/internal mode information;
- Holonomy can classify path-sensitive mode transport;
- Bandwidth can restrict the available fiber;
- Resolution can change the readable representation;
- Occupancy can select the realized channel after admissibility is fixed.

A unique physical gravitational channel would correspond to a source-valid selected
section/equivalence class of this bundle.

No such section is presently recovered.
