# SECOND COMPONENT

Keep the E021 background, source state, and gauge fixed.

Let:
- `v^m` be the E021 unit timelike observer;
- `s^m` be a unit spacelike vector satisfying `v_m s^m = 0`.

Define the second linear functional:

`C_s := s^m s^n (G^(1)_mn[h^G] - kappa DeltaT^+_mn)`.

The E021 stationary tensor equation gives:

`C_s = 0`.

The two functionals:
- `L_u(A)=v^m v^n A_mn`;
- `L_s(A)=s^m s^n A_mn`

are linearly distinct on the symmetric-tensor test space.

Therefore the work layer now has two independent component checks.

This is not an empirical validation and does not prove the full nonlinear tensor theory.
