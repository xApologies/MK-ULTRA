# 6. Chirality, Persistence, Occupancy, and Bandwidth

## Chirality decoration

Let:

```text
chi : Mor(A_B) -> Omega
```

assign chirality/orientation data to admissible transformations or histories.

Bandwidth answers **whether the transformation can be supported**. Chirality answers **how the supported transformation is oriented/organized**.

A chirality-constrained substructure may be written:

```text
A_B^chi subseteq A_B.
```

## Occupancy

Occupancy claims organizational relationships. Represent an occupancy state `O` by a Bandwidth modifier:

```text
M_O : A_B -> A_B|O.
```

Pure occupancy restriction removes incompatible transformations. More general reorganization can redirect or enable alternatives and must be typed accordingly.

## Persistence

Persistence is not identical to low Bandwidth. A persistent structure allocates capacity into stable organization.

Represent a persistence action as:

```text
M_P : A_B -> A_B^P.
```

`M_P` may:

- remove incompatible freedoms;
- stabilize previously fragile composites;
- increase coherence of selected corridors;
- leave unrelated local capacity unchanged.

Therefore “persistence consumes Bandwidth” is true only for the allocated freedoms; global algebraic effect need not be simple scalar subtraction.

## Time Shell

Source material interprets a Time-Shell candidate as a persistent boundary where Resolution and Bandwidth stabilize/constrain organizational expression. In algebraic terms, a Time-Shell is a boundary-localized region where a selected Bandwidth substructure and Resolution quotient remain stable enough to support persistent readout.
