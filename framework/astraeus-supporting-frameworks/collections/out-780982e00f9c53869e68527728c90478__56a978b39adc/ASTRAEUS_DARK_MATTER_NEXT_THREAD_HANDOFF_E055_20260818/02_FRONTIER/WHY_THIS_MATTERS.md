# WHY THIS LINE MATTERS

The dark-matter project began with the narrow question of whether the same readable
matter object could have a hidden substrate distinction that survives enough of the
MK43 machinery to become gravitationally relevant.

The important progression is that the hidden distinction is no longer a fragile
one-off construction.

It now has:

- a fixed local Hydrogen quantum anchor;
- endogenous History generation;
- nonzero conserved continuity response;
- a construction-independent direct-flow quotient;
- multiple same-Q History states;
- cross-probe visibility;
- a saturated driven state;
- projective persistence under relaxation;
- local corridor bottlenecks;
- a family of seven persistent local branches;
- a fixed finite merge-tree architecture;
- a low-dimensional internal weight evolution.

That matters because it changes the character of the candidate.

Instead of:

`one hidden variable -> one anomalous response`

the current work-layer picture is:

`persistent matter anchor`
+
`structured hidden substrate ecology`
+
`local network geometry`
+
`History-dependent but low-dimensional internal state`
+
`source-native continuity response`.

That is a plausible **mathematical architecture** for something dark-sector-like inside
MK43.

What is still missing is decisive and should not be blurred:

the project has not yet shown that two same-Q members of this family produce two
different source-valid readable gravitational states.

That is the line between the current internal result and a physical dark-matter
witness.

The reason to continue E056 is not to accumulate more structure. It is to determine
whether the compact geometry already recovered carries the response-relevant
information. If it does, future gravity work can operate on a small geometric state
instead of a 32^3 History field.
