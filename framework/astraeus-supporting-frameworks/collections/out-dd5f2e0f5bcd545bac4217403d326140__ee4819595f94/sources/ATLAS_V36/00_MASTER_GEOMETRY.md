# 00 — Master Geometry

## Object

Let `T5` be a five-dimensional smooth/fibered Time-Space object equipped with a projection:

```text
pi : T5 -> S3.
```

The present Atlas models localized readable spacetime projections as fibers:

```text
Sigma_p := pi^(-1)(p) ~= S2.
```

Thus, locally:

```text
T5 |_U ~= U x S2
```

for admissible neighborhoods `U subset S3` when the fiber-bundle hypothesis is used.

## Dimensional closure

```text
dim(T5)=dim(S3)+dim(S2)=3+2=5.
```

## Important distinction

The `S2` assignment is an address/projection topology in the current model. It is not a claim that four-dimensional Lorentzian spacetime is literally only a two-dimensional surface. The conventional spacetime degrees of freedom are readable structures represented within the localized projection domain.
