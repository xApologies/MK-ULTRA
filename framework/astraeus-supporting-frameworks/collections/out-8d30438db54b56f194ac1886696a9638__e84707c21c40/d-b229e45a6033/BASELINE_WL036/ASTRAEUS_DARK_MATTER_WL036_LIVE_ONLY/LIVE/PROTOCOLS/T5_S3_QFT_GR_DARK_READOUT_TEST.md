# AST-DM-WL-P003 — T5/S3 Common-Fabric Dark Readout Test

**Work layer:** WL-006  
**Status:** PROTOCOL CANDIDATE — NOT PARENT PROMOTED

## Goal

Test whether a nontrivial `S3` History/holonomy distinction of one five-dimensional Time-Space fabric can be invisible to a selected localized matter/QFT readout while remaining nontrivial in the localized gravity/GR readout.

## Source geometry

Use the Version 1 fibration:

`S2 -> T5 --pi--> S3`

with

`Sigma_p=pi^-1(p)~=S2`.

Use a path

`gamma:[0,1]->S3`

and pullback corridor

`W_gamma=gamma^*(T5)~=S2x[0,1]`

when locally trivial.

## Inputs

Choose two operative formal states `F0,F1` satisfying:

1. same declared formal-object ancestry / compatible identity witness;
2. same localized `S2` target fiber or explicitly typed comparable fibers;
3. same Resolution `R` and compatible Bandwidth scope;
4. a controlled difference only in selected `S3` History / corridor / holonomy organization;
5. no untracked matter-content difference is introduced.

## Test A — matter/QFT quotient

Evaluate the localized matter/QFT representation:

`rho_Q,p,R(F0)` and `rho_Q,p,R(F1)`.

Required dark-candidate condition:

`rho_Q,p,R(F0)=rho_Q,p,R(F1)`.

If an additive difference object is typed, record:

`DeltaF in ker(rho_Q,p,R)`.

Failure here means the selected History difference is already matter-readable at `R` and is not a dark-readout witness of the desired class.

## Test B — gravity/GR separation

Evaluate:

`rho_G,p,R(F0)` and `rho_G,p,R(F1)`.

Required structural separation:

`rho_G,p,R(F0)!=rho_G,p,R(F1)`.

If an additive difference object is typed:

`DeltaF notin ker(rho_G,p,R)`.

This is necessary but not sufficient for physical dark matter.

## Test C — intertwining

For each admitted sector `s`, test the candidate square:

`rho_s,beta o P_gamma^chi = U_s(gamma) o rho_s,alpha`.

At minimum, type and test the gravity sector. Record exact domains, codomains, invariants, and failure conditions.

## Test D — rotational specialization

For the galaxy branch, let the formal difference be carried by the v128/v129 rotational self-History:

- nontrivial relative radial transport / shear;
- nontrivial orientation holonomy;
- cross-Resolution rotational section where available;
- black-hole anchor retained as a local specialization, not a generic corridor requirement.

Require the localized matter readout to remain fixed while the gravity/frame representation is tested for nontriviality.

## Pass classes

`P003-A`: source typing pass only.

`P003-B`: matter-equivalent / gravity-inequivalent formal readout pass.

`P003-C`: gravity intertwining pass under explicit hypotheses.

`P003-D`: accepted downstream gravitational observable mapping and null-model comparison pass.

Only `P003-D` can support physical dark-matter admission. Earlier passes remain mathematical structure.

## Guardrails

- `T5 != S4` in the Version 1 bridge branch.
- `S3 != dark matter`.
- `QFT != GR` and neither is inverted into the other.
- common formal ancestry does not prove identical readout.
- a local matter-null condition is not nonexistence.
- a gravity-non-null condition is not automatically a measured dark-matter signal.
- preserve the parent Dark Matter Atlas v125 branch separately until reconciliation is typed.
