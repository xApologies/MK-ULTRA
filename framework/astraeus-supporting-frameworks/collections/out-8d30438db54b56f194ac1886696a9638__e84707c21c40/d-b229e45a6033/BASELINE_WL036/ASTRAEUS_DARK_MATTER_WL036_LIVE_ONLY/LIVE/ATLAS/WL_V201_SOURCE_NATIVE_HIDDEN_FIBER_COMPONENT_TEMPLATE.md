**QMO:** QMO-AST-DM-WL-085  
**Status:** CANDIDATE COMPONENT REALIZATION / NOT EMBEDDED

Dark Matter 2.2 already types the hidden relational-state bundle as

`pi_H:E_H^R -> T_H`

with fiber

`R_H(t)=(V_t,E_t,w_t,chi_t,H_t)_R`.

The source-native Time-Space chain recovered in WL-v195/v196 supplies objects with each of those component roles:

- `H_t`: `@orientation_history -> @relational_history`;
- `chi_t`: chirality transport / chirality-labelled mote state;
- `V_t`: a finite selected set of chirality-labelled motes at the declared Resolution, as a candidate vertex set;
- `E_t`: ER-throat incidence / adjacency-lattice data;
- `w_t`: weighted adjacency `W_ij>=0`, `W_ij=W_ji`.

This motivates the source-composed candidate

`R_ERH(t;R)=(V_mote^chi(t), E_ER(t), W_ER(t), chi_t, H_rel(t))_R`.

This is not a new ontology and not an identity theorem. The Planck/ER tuple must still be shown to realize an admissible hidden-S3 fiber and to admit a physical constraint-preserving embedding. The value of the match is that the API has supplied concrete data roles for the bundle rather than leaving `R_H(t)` as an empty abstract tuple.
