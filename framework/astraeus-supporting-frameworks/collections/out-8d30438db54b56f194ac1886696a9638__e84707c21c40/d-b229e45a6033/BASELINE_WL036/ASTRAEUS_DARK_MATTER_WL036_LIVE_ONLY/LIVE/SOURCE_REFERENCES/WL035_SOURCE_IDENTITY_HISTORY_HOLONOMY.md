# 04 — History Holonomy and Hidden Identity Change

This module imports the promoted Transduction Geometry T5-T7 structure.

## 1. Closed readable History loop

A History `gamma_H` is closed at the operative/readable level when

```text
Read_R(tgt(gamma_H)) ~ Read_R(src(gamma_H)).
```

This does not imply Formal Identity closure.

## 2. Identity Holonomy

Transport Identity-Witness data around the loop:

```text
Hol_Id(gamma_H)=T_Id(gamma_H).
```

The loop is Identity-trivial when

```text
Hol_Id(gamma_H) ~_Id id.
```

A nontrivial defect means the History returned to the same presentation class without returning to the same Formal Identity class.

## 3. Hidden Identity-Breaking Loop

A loop is hidden identity-breaking when

```text
Read_R(end) ~ Read_R(start)
```

but

```text
Hol_Id(gamma_H) !~_Id id.
```

This is Transduction Geometry D48 / T5.

## 4. Resolution invisibility

If the distinguishing defect is annihilated by the active Resolution quotient, then the Formal Identity change is unreadable at that Resolution. This is T6.

## 5. Chirality coupling

Let

```text
Hol_chi(gamma_H)
```

be chirality holonomy.

If:

1. chirality holonomy is nontrivial;
2. Identity is sensitive to that chirality defect;
3. no compensating witness action cancels the defect;

then Identity holonomy is nontrivial. This is Transduction Geometry T7.

## 6. Atlas consequence

The `S3` continuity domain can carry History memory that is invisible in an `S2` readout. A local projection may therefore close while its global continuity/Identity history does not.
