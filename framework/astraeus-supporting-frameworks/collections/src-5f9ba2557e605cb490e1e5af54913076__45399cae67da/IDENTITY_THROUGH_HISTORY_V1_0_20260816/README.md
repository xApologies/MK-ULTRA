## Purpose

This book types the relationship among:

```text
Persistence
Identity
History
Chirality holonomy
Time-Shell localization
Resolution-dependent readout
```

It is deliberately geometry/algebra first. No differential or integral calculus is native to the construction.

## Central result

The working architecture is:

```text
admissible history
 -> Identity-Witness transport
 -> persistence / recovery distinction
 -> persistence closure
 -> chirality localization
 -> Time-Shell boundary/address
 -> Resolution readout
 -> readable ordering / temporal label.
```

A readable endpoint can return to the same presentation while Formal Identity changes. Conversely, Bandwidth, Resolution, and readable presentation can change while Identity remains fixed when a valid Identity-Witness chain survives.
