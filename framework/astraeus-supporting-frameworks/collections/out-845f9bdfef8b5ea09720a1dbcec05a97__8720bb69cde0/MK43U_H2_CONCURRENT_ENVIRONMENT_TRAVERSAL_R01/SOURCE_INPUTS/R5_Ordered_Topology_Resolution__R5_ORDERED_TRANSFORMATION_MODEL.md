# R5 Ordered Transformation Model

## Concept

R5 converts unresolved shared ecology into constrained topology.

The core operation is:

M_R5 = R_ordered(M_R4, chi_read, B_occ, S_strain, R_rec)

Where:

- M_R4 is the unresolved corridor ecology.
- chi_read is the read-only chirality field.
- B_occ is bandwidth occupancy.
- S_strain is topology strain.
- R_rec is recursive recoverability.
- R_ordered is ordered topology resolution.

## Universal Collapse Target

R5 does not target H2, N2, O2, or any specific molecule.

R5 targets the lowest-strain recoverable constrained topology.

If a pairwise corridor has lower recoverability cost than a three-body ecology, R5 resolves toward pair + free manifold.

Example:

(H3)_proto -> H2 + H

Example:

(N3)_proto -> N2 + N

## Required R5 Rules

1. Chirality is read-only.
2. Corridor formation consumes recoverable chirality capacity.
3. Bandwidth occupancy is finite.
4. Overoccupied corridor networks become unstable.
5. Topology resolution must preserve ancestry.
6. Collapse must be ordered, not destructive.
7. The system must not fully revert to H + H + H unless no pairwise corridor remains recoverable.
8. The system must not force H2 if the manifold ecology does not support it.
9. The resolved state must be exported to R6 for survivability testing.

## Ordered Transformation Trace

Every R5 pass must preserve a trace:

- incoming corridor candidates
- selected corridor(s)
- rejected corridor(s)
- chirality occupancy consumed
- bandwidth occupancy consumed
- strain delta
- ancestry continuity
- recoverability score

This trace is mandatory for later audits.
