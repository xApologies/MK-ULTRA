# R5 Domain Specification
## Ordered Topology Resolution

R5 receives corridor candidates from R4 and resolves them into constrained accessible topology.

R5 is not a blanket bonding rule.
R5 is not an element-specific chemistry table.
R5 is an ordered transformation domain.

## Domain Role

R5 performs:

1. read-only chirality evaluation
2. recoverability scoring
3. bandwidth occupancy evaluation
4. corridor overconstraint detection
5. ordered topology resolution
6. constrained corridor selection
7. topology collapse into accessible coherent configurations

## Key Principle

R5 does not write chirality.

R5 reads chirality and transforms the ecological recoverability landscape.

This means the domain responds to chirality without overwriting chirality.

## Ordered Transformation

R5 implements ordered transformation rather than arbitrary collapse.

For example:

H + H + H may begin to form a proto-H3 ecology.

R5 evaluates whether full three-body corridor occupation is recoverable.

If the triple ecology exceeds stable chirality bandwidth, R5 should resolve the topology toward:

H2 + H

Likewise:

N + N + N may begin to form a proto-N3 ecology.

If one nitrogen corridor consumes recoverable chirality capacity, the third nitrogen should not create unlimited equivalent corridor proliferation.

The resolved state should tend toward:

N2 + N

This must emerge from universal topology constraints, not element-specific rules.

## R5 Inputs

- R4 corridor candidate graph
- read-only chirality map
- elastic strain map
- bandwidth preload map
- topology overlap field
- ancestry register
- local recoverability state

## R5 Outputs

- resolved topology graph
- selected corridor set
- rejected or non-surviving corridor candidates
- bandwidth occupancy map
- constrained chirality occupancy record
- ordered transformation trace
- ancestry-preserving resolved manifold ecology

## R5 Interpretation

R5 asks:

Which corridor topology is the most recoverable constrained topology under chirality, bandwidth, and strain?

R5 does not ask:

Which element-specific molecule should be created?
