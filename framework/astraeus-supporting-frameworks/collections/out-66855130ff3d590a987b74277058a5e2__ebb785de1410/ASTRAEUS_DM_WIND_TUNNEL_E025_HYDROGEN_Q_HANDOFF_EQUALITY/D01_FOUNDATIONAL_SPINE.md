# D01 — Foundational Spine

Let:

```text
T
```

be the Structured Temporal Manifold with temporal metric `g_T`.

Let:

```text
C : T -> T
```

be admissible continuation.

Let:

```text
pi_E : E -> T
```

be the Inherited State Bundle and:

```text
I : E -> E
```

the Inheritance Morphism satisfying:

```text
pi_E o I
=
C o pi_E.
```

Let:

```text
Omega
```

be Chirality Space,

```text
chi : E -> Omega
```

the Chirality Map, and:

```text
tau : Omega -> Omega
```

Chirality Transport satisfying:

```text
chi o I
=
tau o chi.
```

Define admissible equivalence by simultaneous preservation of:

```text
continuation orbit
transported chirality organization
invariant residue.
```

The Persistent Locus is:

```text
Xi
=
{
  xi in E
  |
  exists n >= 1:
  I^n(xi) ~ xi
}.
```
