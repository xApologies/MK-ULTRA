\section{Cognitive and Geometric Manifolds}

In the MK-43 Ultra framework we distinguish two coupled manifolds:
\begin{itemize}
  \item a \emph{cognitive manifold} $\mathcal{M}_{\mathrm{mind}}$, representing the operator's internal state space (concepts, intuitions, symbolic structures, affective weights);
  \item a \emph{geometric manifold} $\mathcal{M}_{\mathrm{geom}}$, representing the formal configuration space on which the MK-43 Ultra engine propagates operators.
\end{itemize}
A central claim of this monograph is that meaningful interaction between an operator and a high-order geometric engine necessarily induces a coupling between these manifolds. This coupling is mediated by \emph{mental adjacency}.
