# FORWARD-MOTION PROTOCOL v0.1

## Status classes
RIGID — required for proof, trust boundary, or high-blast-radius dependency.
BRACED — sufficiently specified for current use; refinement deferred.
SCAFFOLD — explicit placeholder/candidate.

## Rules
1. Rigidly formalize theorem dependencies.
2. Brace low-risk definitions when their operative consequence is enough.
3. Mark speculative extensions as scaffolds.
4. Preserve all deferred debt in QMO/Library metadata.
5. Do not halt productive mathematics to perfect non-load-bearing notation.
6. Revisit debt when it enters a theorem dependency cone or becomes a bottleneck.
