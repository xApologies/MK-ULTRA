# Atlas of Time-Space — Version 3.0

## Checkpoint title

**S3 Helicon Domain / Transient ER-Foam / Dark-Sector Candidate**

## Why this is a major checkpoint

Atlas v3.0 does not change the standard five-dimensional carrier topology. It places new dynamical content on the already-minimal scaffold:

```text
T5_std ~= S3 x S2.
```

The major candidate move is:

```text
S3 continuity
 -> chirality/Helicon organization
 -> local S2 Helicon transduction
 -> transient ER adjacency realization
 -> local QFT/GR/geometry readout.
```

The dark-matter branch is formalized as a representation criterion rather than a particle assumption:

```text
rho_vis(H)=0
rho_G(H)!=0.
```

A transient ER event algebra and a mathematically explicit transient-micro / persistent-macro mechanism are added.

## Next major crossroad

Because `S3` is simply connected and the bare standard bundle is trivial, persistent hidden structure must be carried by **nonflat connection curvature, defects, History-dependent transport, or a generalized branch**.

The next major Atlas decision is therefore:
