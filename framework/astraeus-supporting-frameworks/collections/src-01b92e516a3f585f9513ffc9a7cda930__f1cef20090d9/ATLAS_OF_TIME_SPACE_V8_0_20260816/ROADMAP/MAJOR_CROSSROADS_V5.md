# Atlas Major Crossroads — v5

## Crossroad K — Localization Source Ontology

The mathematics now shows that the minimal smooth carrier can support localized hidden Helicon curvature. The unresolved question is what physically supplies the localization source.

### Branch K1 — Black-hole / galaxy address anchors

Each galaxy-localized `S2` projection carries an anchor datum at its base address `p in S3`.

### Branch K2 — Matter/occupancy backreaction

Visible/local occupancy sources the horizontal Helicon localization field.

### Branch K3 — Spontaneous Helicon/chirality solitons

Localized persistent solutions exist without externally prescribed anchors.

### Branch K4 — Chirality defects / history sectors

Topological or history data localize the connection.

### Branch K5 — Hybrid

One mechanism nucleates the localization and another stabilizes it.

## Rule

Do not select a branch by narrative preference. Prefer the branch that:

1. follows from existing dependency objects;
2. introduces the fewest new free parameters;
3. preserves universal coupling/Bianchi closure;
4. predicts rather than fits the spatial load;
5. retains the old dark-matter rotation/lensing/filament consequences.
