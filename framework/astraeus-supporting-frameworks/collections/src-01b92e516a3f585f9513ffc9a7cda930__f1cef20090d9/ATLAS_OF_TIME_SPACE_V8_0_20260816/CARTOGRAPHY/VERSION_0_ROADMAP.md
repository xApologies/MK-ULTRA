# Version 0 Roadmap

The Version 0 image is the visual seed of the Atlas.

It depicts:

- a single connected global structure;
- multiple localized galaxy-like chambers;
- a central visual nexus;
- luminous continuous scaffold;
- rainbow/chiral flow bands;
- corridor-like connections;
- boundary-like enclosing structure.

## Status warning

The image is an **interpretive roadmap**. Visual topology is not taken literally unless recovered in the formal files.

In particular:

- the central visual nexus is not yet a proved unique chirality source;
- rainbow bands are mnemonic for chirality transport, not literal colored physical streams;
- the outer visible membrane is not automatically a unique global Time Shell;
- local galaxy images symbolize local readable domains rather than proving that every galaxy is literally a topological two-sphere.
