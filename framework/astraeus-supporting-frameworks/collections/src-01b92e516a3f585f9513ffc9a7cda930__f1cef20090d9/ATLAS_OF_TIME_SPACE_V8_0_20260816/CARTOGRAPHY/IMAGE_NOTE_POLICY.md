# Image Note Policy

Every future Atlas version should include at least one image when visual structure materially changes.

Each image must have a companion note containing:

1. image filename;
2. version introduced;
3. objects represented;
4. which visual features are literal mathematical relations;
5. which are physical interpretations;
6. which are mnemonics only;
7. what changed relative to the prior plate;
8. unresolved questions exposed by the image.

The goal is to make images usable by both humans and AI systems without allowing generated aesthetics to silently become canon.
