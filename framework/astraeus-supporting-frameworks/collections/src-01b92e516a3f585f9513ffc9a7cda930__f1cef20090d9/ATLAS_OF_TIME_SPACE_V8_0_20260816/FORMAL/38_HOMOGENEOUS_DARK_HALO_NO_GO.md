# 38 — Homogeneous-Connection Halo No-Go Result

## Proposition 38.1

Let

1. `S3` carry the round homogeneous geometry,
2. `A_H` be invariant under the transitive S3 isometry action,
3. the local dark readout at `p` depend only on local gauge-invariant connection data and use the same equivariant transduction rule at every address.

Then the induced scalar dark-load observables are constant over `S3`.

### Proof sketch

Homogeneity gives, for every pair of addresses `p,q`, an isometry `g` with `g.p=q` preserving the connection up to gauge. Gauge-invariant local data therefore satisfy

```text
I_H(q) = I_H(p).
```

Equivariance of the readout gives

```text
L_H(q) = L_H(p).
```

Hence no localized halo profile can arise from the homogeneous connection alone.

**QED**

## Meaning

This is not a failure of the S3-Helicon idea.

It tells us exactly what additional ingredient the model must contain:

```text
symmetry breaking / address dependence.
```

Possible carriers include

- nonuniform Helicon amplitude `eta(p)`,
- chirality texture / defect structure,
- localized S2 boundary/black-hole anchor data,
- persistent history / Chern–Simons sector,
- coupling to local ER-foam statistics,
- coupling to ordinary matter/boundary occupancy.
