## Dynamic graph state

For a fixed local projection `Sigma_p ~= S2`, define the order-indexed ER state

```text
ER_p[n] = (V_p[n], E_p[n], W_p[n], chi_p[n], rho_p[n], sigma_p[n]).
```

For each admissible ordered pair `(i,j)`, introduce an activation variable

```text
a_ij[n] in [0,1].
```

and an effective edge weight

```text
w_ij[n] = a_ij[n] * wbar_ij[n].
```

An ER incidence is active at threshold `theta_ER` when

```text
a_ij[n] >= theta_ER.
```

## Transient bridge event

An ER event `e_ij` is a finite activated interval

```text
I_ij = { n : a_ij[n] >= theta_ER }.
```

The event lifetime is

```text
tau_ij = |I_ij|
```

in native recursive steps. A readable-time duration may be assigned only after Time-Space projection.

The simplest transient event is

```text
0 -> active -> 0.
```

A reconnection event is

```text
(i,j) active -> closure -> (i,k) active
```

subject to chirality, continuity, and admissibility constraints.

## Discrete update law

Let

```text
Gamma_ij^+[n] = bridge-nucleation propensity
Gamma_ij^-[n] = bridge-closure propensity
R_ij[n]       = bounded reconnection / neighbor forcing.
```

Define the native candidate update

```text
a_ij[n+1]
=
Clip_[0,1](
  a_ij[n]
  + Gamma_ij^+[n] * (1-a_ij[n])
  - Gamma_ij^-[n] * a_ij[n]
  + R_ij[n]
).
```

The propensities are functions of the local S2 realization of the S3 Helicon/chirality state:

```text
Gamma_ij^+ = Gamma_ij^+(H_p^loc, chi_i, chi_j, B, R, Inv, ...)
Gamma_ij^- = Gamma_ij^-(H_p^loc, chi_i, chi_j, B, R, Inv, ...).
```

This keeps the native rule discrete and avoids importing continuum calculus into the substrate definition.

## Continuity carried by an event

Let `C_i[n]` be continuity content at bead/site `i` and `Phi_ij[n]` the continuity transfer along an active ER relation. The recovered native form is

```text
Delta C_i[n]
=
sum_j Phi_ji[n] - sum_j Phi_ij[n]
```

with

```text
Phi_ij[n] = 0  if a_ij[n] < theta_ER.
```

The bridge can be transient while the transferred identity/order/continuity remains recoverable after the edge closes.

## Event algebra

Define primitive event operations:

```text
N_ij  : nucleate(i,j)
P_ij  : persist(i,j)
X_ij  : transfer(i,j)
R_ijk : reconnect((i,j)->(i,k))
C_ij  : close(i,j)
```

Admissible compositions form an event word

```text
w = N P ... X ... R ... C
```

subject to the local admissibility algebra.

The ER foam is therefore not a static set of tubes. It is the evolving event network generated by admissible incidence operations.
