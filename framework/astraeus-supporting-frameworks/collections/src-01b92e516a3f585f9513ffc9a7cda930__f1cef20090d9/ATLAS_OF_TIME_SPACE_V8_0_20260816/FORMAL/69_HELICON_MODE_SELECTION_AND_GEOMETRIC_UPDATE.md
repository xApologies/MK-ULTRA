# 69 — Helicon Mode Selection and Geometric Update

The recovered chirality companion states:

```text
chirality structure
 -> allowed spectral mode
 -> admissible update.
```

Phase III separately defines the local geometric expression operator

```text
U_i(s_i,N(s_i)).
```

Atlas v8 combines these without identifying the operators.

For a local chirality/configuration state `x`, let

```text
Mode(x) = { H_alpha | H_alpha is spectrally/admissibly compatible with x }.
```

Then define a mode-conditioned update relation

```text
x --H_alpha--> x'
```

only when

```text
H_alpha in Mode(x)
```

and the primitive admissibility conditions allow `x'`.

Thus Helicon modes do not merely describe a post-hoc spectrum. They can function as **selectors of which geometric reconfiguration may express**.

This preserves the historical dependency:

```text
chirality structure -> allowed mode -> admissible update
```

while retaining the native rule that time is readable ordering of geometric expression rather than a fundamental update parameter.
