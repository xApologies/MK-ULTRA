# 49 — Native Direction Bundle and Smooth UT(S3) Readout

Let `S3_cont` denote the continuity-domain topology. At each address `p`, let `Dir(p)` be the set/class of admissible local directions/orientations available there.

Define the native five-dimensional carrier schematically as

```text
DirT(S3_cont) = disjoint union over p in S3_cont of Dir(p).
```

Current Atlas physical/readable assignment requires

```text
Dir(p)  ->  S2_p
```

under the smooth/local geometric readout.

When `S3_cont` is represented as a smooth 3-sphere and `Dir(p)` is the unit tangent-direction sphere, then

```text
DirT(S3_cont)  ->  UT(S3)
UT(S3) ~= S3 x S2.
```

Therefore the v5 Unit Tangent Bundle result remains a strong smooth realization, but it is not forced to be the native definition of Time-Space.
