# 29 — Atlas v3 Cartographic Propositions

## Proposition V3-P1 — Transient-link persistence

Let `a_ij[n]` be a stationary ergodic bounded activation process for each finite edge family. Then the Cesaro mean

```text
Abar_ij^(N)=(1/N) sum_n a_ij[n]
```

converges almost surely to `E[a_ij]`.

**Consequence:** microscopic ER incidences may be individually transient while their coarse-grained adjacency/load is persistent.

## Proposition V3-P2 — Corridor realization of S3 Helicon transport

For a path `gamma:I->S3`, the standard Time-Space pullback is

```text
W_gamma = gamma^*T5 ~= S2 x I.
```

If `E_H->S3` carries a connection, then `gamma` induces a Helicon parallel transport map `P_gamma^H`; `W_gamma` supplies the associated family of local S2 transductions.

**Consequence:** the same mathematical corridor simultaneously carries address continuity and S3 Helicon transport.

## Proposition V3-P3 — Dark-sector representation criterion

If a local Helicon state `H` satisfies

```text
rho_vis,p(H)=0
rho_G,p(H)!=0,
```

then it is gravitationally readable without an ordinary visible/matter readout at the same projection.

This is a definition-level proposition, not evidence that nature contains such states.

## Proposition V3-P4 — Bianchi closure constraint

If the local Einstein representation is

```text
G_mn = kappa(T_mn^vis + T_mn^H),
```

then the contracted Bianchi identity requires

```text
nabla^m(T_mn^vis + T_mn^H)=0.
```

Therefore every Atlas dark-sector map must provide either separate conservation or an explicit exchange current.

## Proposition V3-P5 — Flat S3 is insufficient for hidden topological load

From v2.0, `S3` is simply connected and the standard carrier is topologically `S3 x S2`. Therefore persistent nontrivial S3 Helicon structure cannot be justified by bare global bundle twisting alone.

It must be supported by at least one of:

- nonzero Helicon/chirality connection curvature,
- defect/singularity set,
- restricted domain topology,
- history-dependent/nonlocal transduction,
- generalized geometry beyond the standard smooth branch.

This becomes the next major Atlas crossroad.
