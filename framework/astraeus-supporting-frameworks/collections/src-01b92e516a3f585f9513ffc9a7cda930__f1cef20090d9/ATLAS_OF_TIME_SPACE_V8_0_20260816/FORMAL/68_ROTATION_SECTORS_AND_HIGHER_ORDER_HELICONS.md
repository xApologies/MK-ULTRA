# 68 — Rotation Sectors and Higher-Order Helicons

The recovered Helicon archive includes

```text
H^(k)=R^k H
```

and the half-turn equivalence

```text
H(theta+pi)=H(theta).
```

Atlas v8 expresses this as a group action on Helicon configuration classes.

Let `G_R=<R>` be the generated rotation action on the Helicon quotient.

If admissibility is rotation-equivariant,

```text
A_H^Q(Ra,Rb)=A_H^Q(a,b),
```

then

```text
T_H^Q R = R T_H^Q
```

and therefore

```text
L_H^Q R = R L_H^Q.
```

Hence the Helicon mode space decomposes into invariant rotation sectors.

The historical half-turn rule selects the sector on which

```text
R_pi H = H.
```

Higher-order Helicon modes are then naturally represented by the orbit / representation structure of repeated `R` action rather than by a differential angular generator at the native layer.

This provides a geometry/algebra replacement for the recovered smooth expression

```text
A = -partial_theta G.
```

which remains valid only as a downstream smooth representation when appropriate.
