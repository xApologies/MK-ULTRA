# 25 — Helicon Radiative / Non-Radiative Decomposition

## Candidate decomposition

Let the S3 Helicon state space admit two invariant or approximately invariant sectors:

```text
H_p = H_p^D (+) H_p^R
```

where

- `H^D` = persistent / non-radiative continuity organization,
- `H^R` = propagating / radiative mode sector.

For a global section,

```text
H_3 = H_D + delta H_R.
```

This is a decomposition target, not yet a proved orthogonal direct sum.

## Radiative branch

The recovered gravity chain is retained:

```text
delta H_R
 -> gravitational Helicon mode H_g
 -> graviton
 -> continuity perturbation
 -> Time-Shell metric projection
 -> h_mn
 -> gravitational-wave / metric dynamics.
```

## Persistent branch

The candidate dark branch is

```text
H_D
 -> persistent continuity organization
 -> persistent statistics of transient ER incidence
 -> local effective geometric load
 -> dark-matter-like gravitational readout.
```

## Crucial non-identity

```text
DarkMatter != Graviton
```

and

```text
H_D != H_g.
```

They are proposed as different regimes/sectors of one larger Helicon continuity domain.

## Spectral criterion

If `L_H` is the Helicon spectral operator, a useful formal target is to identify spectral subsets

```text
Spec_D(L_H)  = non-radiative / persistent band
Spec_R(L_H)  = radiative / propagating band.
```

A mode-selection functional may depend on persistence, group velocity/readable propagation, closure, and coupling to local QFT readout.

No threshold is asserted in v3.0; the point is to make the split mathematically addressable.
