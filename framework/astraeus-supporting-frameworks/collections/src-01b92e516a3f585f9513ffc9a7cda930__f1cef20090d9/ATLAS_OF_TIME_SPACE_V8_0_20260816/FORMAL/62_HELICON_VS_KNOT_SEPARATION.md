# 62 — Helicon vs Knot Separation in Unit-String Configuration Geometry

Recovered AERA distinguishes:

```text
Helicon = propagating / restructuring-dominant coherent mode
Knot    = localized / continuity-lock-dominant stable topology.
```

Atlas v7 preserves that distinction inside the Unit-String configuration architecture.

## Helicon branch

A Helicon-compatible configuration family is identified by coherent circulation, orientation transport, continuity redistribution, and topology/winding while remaining propagation-capable.

## Knot branch

A knot-class configuration requires localized closure invariants such as stable topology, continuity equilibrium, orientation closure, and persistence under geometric expression.

## Shared ancestry

Both branches may arise from the same native configuration/path algebra:

```text
normalized continuation configurations
          |
          +--> coherent quotient modes --> Helicon
          |
          +--> localized closure classes --> Knot / particle
```

This prevents the Unit String from being prematurely identified with either a particle or a field carrier.

## Hybrid branch

Recovered AERA explicitly allows Helicon-knot hybrids. Atlas v7 interprets these as configuration families possessing both a localized persistent core and a coherent propagating quotient sector.
