# 36 — Effective-Source Channel vs Geometric-Load Channel

## Two mathematically distinct realizations

### Channel A — effective source

```text
G_mn[g]
=
8 pi G (T_mn^vis + T_mn^H).
```

Here the Helicon dark sector is represented by an effective local source tensor.

### Channel B — geometric load

```text
g = g_vis + Delta g_H
```

with

```text
G_mn[g_vis + Delta g_H]
=
8 pi G T_mn^vis.
```

Dark matter is then the apparent source reconstructed by comparing the full geometry to the visible-source background.

## Equivalence condition

The channels are observationally interchangeable on a stated domain only if

```text
8 pi G T_mn^H
=
G_mn[g_vis + Delta g_H] - G_mn[g_vis]
```

with all nonlinear terms retained at the selected approximation order.

This relation is a **representation equivalence**, not an ontological identity.

## Bianchi compatibility

Channel B automatically inherits

```text
nabla_full^m G_mn[g_full] = 0.
```

Channel A must ensure

```text
nabla_full^m (T_mn^vis + T_mn^H) = 0.
```

The geometric-load channel is therefore the cleaner primary representation for a sector whose historical identity is geometry rather than ordinary matter.

## Atlas v4 preference

Use Channel B as the **primary dark-sector geometry representation**.

Retain Channel A as the observer-facing/effective-source translation used for comparison with conventional dark-matter phenomenology.
