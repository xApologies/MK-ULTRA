# 01 — Fibration and Address Atlas

## Local addresses

A point `p in S3` is a continuity address.

Its localized spacetime projection is:

```text
Sigma_p := pi^(-1)(p).
```

The address is therefore not merely a coordinate in an already-given spacetime. It selects an entire local readable projection domain.

## Atlas charts

Let `{U_i}` cover `S3`. For a locally trivial fibration, each chart has a trivialization:

```text
phi_i : pi^(-1)(U_i) -> U_i x S2.
```

On overlaps `U_i intersect U_j`, transition data acts on the `S2` fiber.

A major v1.0 question is whether the actual Time-Space object should be:

1. a standard smooth `S2` bundle;
2. a bundle plus nontrivial connection/holonomy data;
3. a singular/stratified fibration;
4. a more general transduction-geometric carrier.

## First major mathematical crossroad

For an ordinary oriented `S2` sphere bundle over `S3` with structure group reducible to `SO(3)`, the bare bundle topology is strongly constrained and is expected to be topologically trivial. If the desired nontrivial structure is real, it should therefore reside primarily in connection/transport/chirality data, or the fibration class must be generalized.

This is the first checkpoint that should be frozen before changing the global topology.
