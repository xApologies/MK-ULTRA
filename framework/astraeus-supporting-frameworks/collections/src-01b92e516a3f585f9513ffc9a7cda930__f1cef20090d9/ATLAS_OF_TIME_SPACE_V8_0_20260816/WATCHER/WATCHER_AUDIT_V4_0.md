# Watcher Audit — Atlas of Time-Space v4.0

## W4-1 — Nonflat connection on trivial carrier

**PASS — ESTABLISHED DIFFERENTIAL GEOMETRY.**

A topologically trivial bundle over simply connected S3 can carry a smooth nonflat connection and nontrivial curvature-generated holonomy.

## W4-2 — SU(2) test representation

**PASS AS TEST MODEL / NOT PHYSICAL IDENTIFICATION.**

`S3 ~= SU(2)` makes the Maurer–Cartan ansatz mathematically natural. Atlas v4 does not promote the Helicon internal group to physical SU(2).

## W4-3 — Curvature formula

**PASS.**

For `A_k=k theta` and `dtheta + theta^2=0`,

```text
F_k=k(k-1) theta^2.
```

## W4-4 — Corridor memory

**PASS.**

Nonzero curvature can produce nontrivial holonomy on contractible loops. Bare `pi_1(S3)=0` is therefore not a no-go for path memory.

## W4-5 — Chern–Simons history

**PASS AS MATHEMATICAL CANDIDATE.**

The 3D base naturally admits a Chern–Simons functional. Its identification with physical chirality/Helicon history remains unproved.

## W4-6 — Homogeneous halo result

**PASS UNDER STATED EQUIVARIANCE HYPOTHESES.**

A homogeneous connection plus address-independent equivariant local readout yields spatially homogeneous local invariants and therefore cannot create localized halo profiles by itself.

## W4-7 — Variable connection localization

**PASS AS FORMAL SOCKET / STABILITY OPEN.**

`A_eta=eta theta` is a valid smooth ansatz. No stable physical `eta` profile is yet derived.

## W4-8 — Geometry-first dark representation

**PASS AS A CLEANER REPRESENTATION CHOICE.**

Mapping hidden continuity first to `Delta g_H` and only secondarily to apparent `T_DM` is compatible with the historical relational-geometry interpretation and avoids prematurely declaring a new particle fluid.

## W4-9 — Bianchi compatibility

**PASS AS STRUCTURAL REQUIREMENT.**

The full metric Einstein tensor is divergence-free. Any effective-source translation must use the full connection/metric and preserve the corresponding conservation law.

## W4-10 — Exotic topology

**NOT REQUIRED AT v4.**

The smooth nonflat branch survives. Introducing singular/global exotic Time-Space before testing localization would add unsupported structure.

## Watcher conclusion

Atlas v4 resolves the previous global-structure crossroad in favor of the minimal smooth carrier and produces the first genuine no-go result of the S3-Helicon dark-sector branch: a perfectly homogeneous hidden connection cannot explain localized dark halos. The model now has a sharply defined next problem rather than an ontology problem.
