# Large Source Pointers

Large archival sources are not duplicated in this Atlas ZIP when a smaller source snapshot or prior foundation already captures the active model. Their hashes are preserved in `SOURCE_MANIFEST.json`.

Pointer-only sources currently include:

- `BRIDGE(6).zip`
- `Tests(4).zip`
- `MK Ultra(2).pdf`
- `MK Ultra Companion .pdf`

These remain external evidence archives rather than Atlas working files.
