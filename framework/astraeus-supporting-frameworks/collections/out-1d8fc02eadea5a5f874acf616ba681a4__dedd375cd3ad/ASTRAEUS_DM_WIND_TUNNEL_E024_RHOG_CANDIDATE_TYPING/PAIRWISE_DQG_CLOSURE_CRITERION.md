# E024 — Minimal Pairwise Closure Criterion for the Canonical Dark Defect

Let `F0,F1` be two valid operative states in the common chirality-fabric domain.

Let `rho_Q : F -> Q_QFT` be the completed quantum representation.

Let a typed gravitational continuation factor locally as

`rho_G = K_G o sigma_pre`

where `sigma_pre` is the already-observed pre-gravitational response stage
and `K_G` is the remaining gravitational-helicon / TT / Time-Shell /
metric-curvature continuation.

For one pair, the following are sufficient:

1. `rho_Q(F0) = rho_Q(F1)`;
2. `sigma_pre(F0) != sigma_pre(F1)`;
3. `K_G(sigma_pre(F0)) != K_G(sigma_pre(F1))`.

Then, by definition, the pair belongs to

`D_QG = { (F0,F1) | rho_Q(F0)=rho_Q(F1), rho_G(F0)!=rho_G(F1) }`.

A global injectivity theorem for `K_G` is NOT required.
Only pairwise non-collapse of the already-observed separation is required.
