# E030 — Hydrogen Resolution Excursion

## Anchor

Use the full intrinsic Hydrogen ancestry as the base node:

`R_H^0 := C_H`

with no environmental History feature readable.

At this base:

`rho_Q,H^anchor(F_fresh) = rho_Q,H^anchor(F_conditioned) = [Q_H]`.

## Contextual refinement

Let:

`E_H = {chi, adjacency, corridor, persistence}`

be the four contextual History features from E029.

A monotone refinement path is an ordering of those four features.

There are:

`4! = 24`

such paths from the same intrinsic Hydrogen anchor to the same full contextual endpoint.

Every path reaches the same readable feature set:

`C_H union E_H`

but carries a distinct ordered History word.

## Closed excursion

For each refinement order:

`e_1, e_2, e_3, e_4`

take the reverse coarsening sequence:

`e_4, e_3, e_2, e_1`.

The readout returns to the intrinsic Hydrogen anchor.

Thus each excursion satisfies:

`coarse H -> contextual fine -> coarse H`

with:

`initial coarse readout = final coarse readout = [Q_H]`.

However, by the UTO rule, the path is appended to History.

Therefore:

**readout closure does not imply History erasure.**

## What happens to the fresh/conditioned distinction

At the intrinsic H node:

the pair is readout-equal.

At any node containing at least one environmental History feature:

the pair is distinguishable in the E029 exact-array model.

After the last contextual feature is forgotten:

the pair is again readout-equal.

The underlying E004 pre-gravitational separation is not created by the Resolution view
operation and is not deleted by returning to the coarse readout.

The present source stack does not define a Resolution-indexed UCM response operator, so
E030 does not claim that the numeric pre-G response changes as a function of the
Resolution path.

## Elementary Resolution squares

Any two contextual features `a,b` generate two monotone paths from the same base to
the same two-feature endpoint:

`a then b`

and

`b then a`.

There are:

`C(4,2)=6`

such elementary squares.

These are the minimal closed loops on which a Resolution-space connection could be
tested for order dependence / holonomy.

If transport is flat/commuting on a square, the loop holonomy is trivial.

If the source-valid connection is order-sensitive, the same endpoint can carry a
nontrivial accumulated transport record.

No connection instance is currently available, so holonomy values remain open.

## Main result

Hydrogen supports a genuine algebraic Resolution excursion:

`same anchor`
-> `distinction becomes readable`
-> `same full fine endpoint reached by many histories`
-> `coarsening closes the readout`
-> `History remains recorded`.

This is the closest exact analogue yet of the proposed Resolution "bump" around a
stable anchor.
