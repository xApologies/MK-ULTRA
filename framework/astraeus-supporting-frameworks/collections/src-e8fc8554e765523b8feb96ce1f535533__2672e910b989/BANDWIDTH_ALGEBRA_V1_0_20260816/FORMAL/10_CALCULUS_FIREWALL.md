# 10. Geometry-First / Calculus Firewall

Bandwidth Algebra v1.0 contains no native derivative or integral.

Preferred native operations:

- typed path composition;
- restriction/expansion;
- boundary/address relations;
- occupancy constraints;
- chirality decoration;
- holonomy/coherence defects;
- Resolution quotients;
- algebraic-geometric translation;
- finite/recursive spectral operators.

Downstream smooth readouts may use calculus when mapping to conventional physics.

Examples:

```text
native path valuation ell(c)=1
  -> smooth readout integral ds = 1

native same-endpoint transport defect
  -> smooth curvature tensor / differential-form representation

native finite conservation ledger
  -> continuum divergence law
```

The readable calculus expression is not allowed to silently redefine the native object.
