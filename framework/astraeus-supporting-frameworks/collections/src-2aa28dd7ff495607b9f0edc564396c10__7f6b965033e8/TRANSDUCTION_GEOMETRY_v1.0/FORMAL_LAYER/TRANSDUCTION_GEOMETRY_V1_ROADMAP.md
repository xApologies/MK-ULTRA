# 4. Stage A — Cross-Resolution Bandwidth

Goal:

```text
Hold one Bandwidth object fixed
while allowing it to appear across multiple Resolutions.
```

Primary questions:

```text
A1. What is the identity of a Bandwidth across Resolution levels?

A2. What data is invariant under Resolution change?

A3. What data is quotient-collapsed or newly resolved?

A4. Can the same Bandwidth class induce different Observational Identities
    while preserving Formal Identity?

A5. What maps connect Resolution levels?

A6. Are these maps functorial, filtered, inverse-system-like,
    direct-system-like, or something weaker?

A7. How does Chirality Holonomy appear at coarse versus fine Resolution?
```

Minimum deliverables:

```text
Cross-Resolution Bandwidth object
Resolution-indexed Bandwidth family
Resolution transition maps
Formal/Observational persistence statement
at least one nontrivial theorem or counterexample
```

Exit criterion:

```text
One Bandwidth can be represented coherently
across a Resolution hierarchy.
```

Priority: P0.
