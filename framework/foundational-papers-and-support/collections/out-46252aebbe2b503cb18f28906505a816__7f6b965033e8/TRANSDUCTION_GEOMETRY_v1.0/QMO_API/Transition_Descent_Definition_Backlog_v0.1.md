# TRANSITION / DESCENT DEFINITION BACKLOG v0.1

Required before deciding whether a cocycle/descent axiom is independent:

## D15 — Overlap Domain
Formal domain on which two local presentations are simultaneously valid.

## D16 — Transition Map
Typed map relating local state presentations on an overlap.

## D17 — Valid Triple Overlap
Region/domain on which three local presentations and pairwise transition maps coexist.

## D18 — Descent Defect
Typed composite measuring failure of transition closure on a triple overlap.

## D19 — Descent Equivalence
Declared equivalence relative to which a descent defect counts as trivial/coherent.

Candidate axiom after these definitions:
A4 — Transition Cocycle Coherence.
