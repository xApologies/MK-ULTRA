# TRANSDUCTION THEOREM CANDIDATES v0.1

## T0 — Global Realization Existence
Candidate statement:
Every descent-compatible local family X is realizable.

Form:
D21(X) -> Realizable(X).

Status: UNPROVED.

## T1 — Global Realization Uniqueness
Candidate statement:
Every descent-compatible local family X has exactly one global realization class.

Form:
D21(X) -> |RealClass(X)| = 1.

Status: UNPROVED.

T1 is strictly stronger than T0.
