# System Overview

Library⁵ is a generic mathematically indexed recovery engine. It may remain empty and still be operational. Domain knowledge is introduced through validated address packages or model packages.

Human request → human-facing AI → runtime → BRANE → AI⁵ interpretation → API⁵ canonical domain → AI⁵ finite realization → BRANE private QMO⁶ → Library⁵ address recovery → BRANE artifact projection → runtime → human-facing AI → user.

Library⁵ stores active mathematical addresses, complete packages, model membership, provenance, and version history. It supports population, replacement, removal, purge, exhaustive recovery, and QMO-shaped returns. It does not choose traversal, originate API handles, summarize by default, own final report organization, expose unrestricted SQL, or invent missing content.
