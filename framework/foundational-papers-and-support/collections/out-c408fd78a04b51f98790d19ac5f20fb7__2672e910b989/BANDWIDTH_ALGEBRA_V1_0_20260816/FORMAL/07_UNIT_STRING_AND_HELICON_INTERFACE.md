# 7. Unit String / Helicon Interface

This file applies Bandwidth Algebra to the Atlas v6 geometry-first refactor.

## Unit String configuration algebra

Let `U_1` be the set/class of admissible Unit-String configurations satisfying a native invariant valuation:

```text
ell(c) = 1.
```

No integral is required in the native definition.

Let `A_B(U_1)` be the Bandwidth Algebra generated by admissible reconfiguration moves among normalized Unit-String states.

A configuration move:

```text
u_i -> u_j
```

belongs to Bandwidth iff it is currently admissible and supportable.

## Configuration graph

Construct:

```text
C_1 = (U_1, E_B)
```

where `E_B` contains Bandwidth-admissible reconfiguration edges.

## Candidate Helicon spectral operator

If a linear spectral readout is required, form a weighted graph/configuration operator, for example:

```text
L_conf = D - W
L_conf H_n = lambda_n H_n.
```

This is a candidate bridge to the recovered Helicon spectral equation. It is not yet an identity.

The key point is methodological:

```text
Bandwidth Algebra decides which configurations/moves exist.
Helicon spectralization analyzes coherent modes of that admissible configuration geometry.
```

Calculus-based Jacobi/string operators are retained only as downstream smooth specializations if later required.
