# 4. Resolution and Readout

Source rule:

```text
Resolution = Distinguishable Organization.
Bandwidth  = Available Organizational Freedom.
```

They answer different questions and must not collapse into one variable.

## BA-D13 — Resolution congruence/filter

For a Resolution `R`, let `K_R` identify formal distinctions that cannot be distinguished at `R`.

## BA-D14 — Resolution algebra

```text
rho_R : A_B -> A_B^R
A_B^R = A_B / K_R.
```

`rho_R` may be non-injective:

```text
a != b
but
rho_R(a) = rho_R(b).
```

Thus distinct formal corridors can be observationally identical.

## BA-D15 — Cross-resolution compatibility

For finer `R_j` and coarser `R_i`:

```text
rho_Ri = q_ji o rho_Rj
```

with:

```text
q_ji : A_B^Rj -> A_B^Ri.
```

This formalizes the recovered statement:

```text
Multiple Resolutions can inherit from the same Bandwidth.
```

## BA-D16 — Resolution geometry

Transduction Geometry supplies the generalized algebraic-geometric readout:

```text
Geo_R(B) = Spec_T(A_B / K_R).
```

Hence:

```text
formal transformation capacity
 -> Resolution quotient
 -> readable geometry.
```

This is the preferred geometry-first translation layer.
