# Executive Summary

The source definition is:

```text
Bandwidth = Available Organizational Freedom.
```

Resolution answers **what can be distinguished**. Bandwidth answers **what can still emerge / transform / be supported**.

The v1.0 formalization separates three levels that older notes sometimes compressed into the same symbol `B`:

1. **Formal Bandwidth Algebra** `A_B`: the typed set of admissible transformations and their compositions.
2. **Resolution Readout** `A_B^R = A_B / K_R`: what of that formal capacity is distinguishable at Resolution `R`.
3. **Scalar Bandwidth Valuation** `beta(A_B)`: an optional numerical summary used only where a scalar equation requires it.

This distinction lets one Bandwidth object appear at many Resolutions without pretending each Resolution owns an unrelated Bandwidth.

## Geometry-first rule

No derivative, integral, or smoothness assumption is required to define Bandwidth Algebra. Smooth calculus expressions are allowed only as downstream representations when mapping to conventional QFT/GR.
