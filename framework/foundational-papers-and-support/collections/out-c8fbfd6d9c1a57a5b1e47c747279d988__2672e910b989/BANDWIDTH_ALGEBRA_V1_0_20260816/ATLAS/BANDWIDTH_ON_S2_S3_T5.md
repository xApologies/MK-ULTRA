# Bandwidth on S2, S3, and T5

The Atlas presently distinguishes:

```text
T^5  = five-dimensional Time-Space
S^3  = continuity domain/base
S^2  = localized readable spacetime projection/fiber
```

Bandwidth should not be forced to be one uniform scalar across these domains.

Define local typed structures:

```text
A_B(T^5)
A_B(S^3)
A_B(S^2_p)
```

with declared restriction/transduction maps where valid.

Candidate architecture:

```text
A_B(T^5)
  -> horizontal/continuity Bandwidth A_B(S^3)
  -> local projection Bandwidth A_B(S^2_p)
```

The exact functorial relation is BRACED pending Atlas v6. What is already fixed is that a local `S^2` projection can be saturated while the larger `S^3`/`T^5` structure retains organizational freedom, matching the source statement that Bandwidth is distributed rather than uniform.
