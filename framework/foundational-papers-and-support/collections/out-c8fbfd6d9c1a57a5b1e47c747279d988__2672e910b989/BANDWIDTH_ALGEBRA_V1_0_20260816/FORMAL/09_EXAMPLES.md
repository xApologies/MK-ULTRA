# 9. Working Examples

## Example A — Empty room

Many reconfiguration generators remain available:

```text
|Free_B(room)| is large in a finite readout.
```

High Bandwidth does not imply high Resolution.

## Example B — Filled room

Occupancy removes/blocks many admissible transformations. The room remains a valid state while its nontrivial transformation set approaches saturation.

## Example C — Same Bandwidth, multiple Resolutions

Fix `A_B`.

At coarse `R_0`, two furniture arrangements may be observationally identical:

```text
rho_R0(a)=rho_R0(b).
```

At finer `R_1`:

```text
rho_R1(a)!=rho_R1(b).
```

The Bandwidth did not change. Readability did.

## Example D — Atomic manifold coupling

Two persistent atomic manifold states may have a coupling corridor only if the corresponding transformation word belongs to `A_B` after chirality and occupancy constraints are applied.

Chemistry-like coupling therefore becomes an admissible-capacity question before downstream physical realization.

## Example E — Unit String

All Unit-String configurations satisfy native invariant `ell(c)=1`. Bandwidth determines which shape/configuration transitions remain admissible. Resolution determines which of those distinctions are readable.

This gives a calculus-free formal core for the current S3/Helicon cartography.
