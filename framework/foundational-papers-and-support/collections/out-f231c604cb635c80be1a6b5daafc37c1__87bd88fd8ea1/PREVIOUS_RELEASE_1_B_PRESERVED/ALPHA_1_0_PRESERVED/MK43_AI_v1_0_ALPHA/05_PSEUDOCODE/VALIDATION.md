# Collapse Validation Pseudocode

```text
FUNCTION VALIDATE_COLLAPSE(collapse, tree, policy, context):
    ASSERT collapse.root == tree.root
    ASSERT ALL_REALIZED_HANDLES_RESOLVE()
    ASSERT ALL_CANONICAL_CLAIMS_HAVE_PROVENANCE()
    ASSERT EVERY_ENCOUNTERED_BRANCH_IS_ACCOUNTED_FOR_ONCE()
    ASSERT EVERY_TERMINATED_BRANCH_HAS_CONTINUATION_IF_ENABLED()
    ASSERT NO_QMO_INTERNAL_OBJECT_IS_EXPOSED()
    ASSERT NO_CANONICAL_FINGERPRINT_CHANGED()
    ASSERT ORDER_IS_DETERMINISTIC_FOR_IDENTICAL_INPUTS()
    ASSERT BUDGETS_WERE_NOT_EXCEEDED()
    RETURN SIGNED_OR_HASHED_VALIDATION_RECEIPT()
```
