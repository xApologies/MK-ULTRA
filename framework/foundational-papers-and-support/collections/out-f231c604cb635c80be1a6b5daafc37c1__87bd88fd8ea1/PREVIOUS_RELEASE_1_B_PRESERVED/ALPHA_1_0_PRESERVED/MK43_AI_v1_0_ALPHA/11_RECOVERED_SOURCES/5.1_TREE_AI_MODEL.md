The API remains a canonical recursive graph.

The API AI interfaces with the API exclusively through the Tree model.

## Tree Object

Tree
├── Root
├── Trunk (Primary Spine)
├── Major Branches
├── Minor Branches
├── Terminal Branches
├── Leaf Clusters
├── Frontier
└── Continuation Handles

---

## API AI Loop

1. Receive recovery request.
2. Recover canonical graph from API.
3. Construct Tree object.
4. Expand recursively.
5. For each candidate branch:
      evaluate traversal policy.
6. CONTINUE:
      add branch.
7. TERMINATE:
      create Leaf Cluster.
      expose continuation handle.
8. Repeat until every active branch terminates.
9. Return TreeRecoveryObject.

---

## Learning Objective

The API AI does NOT learn mathematics.

The API AI does NOT modify canonical handles or edges.

The API AI learns only:

- where trunks naturally emerge
- branch ordering
- branch termination
- leaf-cluster placement
- frontier quality
- teaching-tree coherence

The canonical graph remains invariant.

---

## Traversal Policy

Decision:

CONTINUE
or
TERMINATE

Termination produces a Leaf Cluster.

A Leaf Cluster marks the boundary of the current teaching tree and becomes the entry point for future recoveries.

---

## Canonical Principle

The API discovers the graph.

The Tree organizes the graph.

The AI learns the Tree.

The Runtime transports the Tree.

The Human explores the Tree.
