# System Overview

## Pipeline

```text
Human-facing AI
      ↓ normalized request
BRANE 2.1
      ↓ private request context
AI⁵
      ↔ API⁵
      ↔ Library⁵
      ↓ ordered finite realization
private QMO⁶
      ↓ projection
artifact / report
```

AI⁵ is the cognitive control module. It does not own canon, recovered library bodies, or the QMO lifecycle. It converts a normalized request and API capabilities into a finite, coherent, auditable realization policy.

## Ownership

| Component | Owns |
|---|---|
| API⁵ | handles, equations, dependency graph, provenance, recursive recovery |
| AI⁵ | intent, ranking, continuation, termination, collapse, validation |
| Library⁵ | content recovery, models, analogies, explanations, assembled chunks |
| BRANE⁶ | module isolation, chirality lift, QMO lifecycle, privilege enforcement, artifact projection |

## Non-goals

AI⁵ does not rewrite canonical data, fabricate handles, silently erase branches, or expose the private QMO.
