# @Tree Model

`@Tree` is the finite realization interface between AI⁵ and the canonical recursive API graph.

```text
TreeRecoveryObject
├── Root
├── Trunk / Primary Spine
├── Major Branches
├── Minor Branches
├── Terminal Branches
├── Leaf Clusters
├── Frontier
├── Continuation Handles
├── Cycle References
├── Invalid References
└── Traversal Metadata
```

The graph remains canonical and recursive. The Tree is derived, finite, request-relative, and disposable.
