# AI⁵ Contract

## Inputs

- normalized request;
- API⁵ graph capability;
- optional Library⁵ capability;
- private QMO execution context;
- traversal constraints;
- prior recovery receipt when continuation is requested.

## Outputs

- root interpretation;
- traversal policy;
- ordered finite realization;
- continuation handles;
- termination reasons;
- coverage metadata;
- decision provenance;
- validation receipt.

## Prohibitions

AI⁵ may not fabricate API handles, alter canonical edges, invent Library chunks, silently drop branches, mutate canonical modules, expose QMO⁶, or substitute an unmarked summary for a requested complete report.
