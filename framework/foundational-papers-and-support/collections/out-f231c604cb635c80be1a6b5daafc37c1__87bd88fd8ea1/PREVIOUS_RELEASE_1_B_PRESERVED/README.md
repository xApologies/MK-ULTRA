# MK43 AI 1.B

Executable realization of AI 1.0 Alpha for BRANE 2.1.

## Role

The API owns canonical recursion. AI 1.B owns request interpretation, deterministic branch ranking, continuation/termination/defer/reject decisions, finite tree realization, continuation placement, collapse ordering, decision provenance, and collapse validation. BRANE owns QMO realization and transport. The Library owns substantive content bodies.

## Load

Use BRANE 2.1 `PortLoader.from_zip(..., PortKind.AI, expected_sha256=...)`.

## Alpha preservation

The complete accepted AI 1.0 Alpha is included under `ALPHA_1_0_PRESERVED/`.
