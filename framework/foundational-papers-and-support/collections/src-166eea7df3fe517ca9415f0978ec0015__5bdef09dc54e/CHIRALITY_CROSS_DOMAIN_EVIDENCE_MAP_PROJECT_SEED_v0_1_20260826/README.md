## Mission

Determine the exact organizational grammar called **chirality** that is being reused across the project's domains, and separate:

1. source-established mathematics;
2. implemented computer architecture;
3. internal simulation/model evidence;
4. cross-domain structural correspondence;
5. externally validated physical claims.

This project does **not** begin by assuming that every use of the word chirality is mathematically identical, physically identical, or evidence for fundamental physics.

Its job is to find the common invariant if one exists, identify type changes where it does not, and produce a source-audited evidence atlas that a skeptical reviewer can query without trusting conversational memory.

## Hard firewalls

- Engineering utility does not by itself prove a physical ontology.
- A repeated 3+1+1 label across projects is not automatically the same mathematical object; types must be audited.
- Domain-specific payloads may differ while a common organizational grammar survives.
- Cross-domain reuse is evidence of generality/utility, not automatically evidence of nature.
- Internal simulation agreement is not external experimental validation.
- LIGO/gravity compatibility claims require their own source receipts/logs before promotion.
- MMO history must be source-recovered before exact package/version claims are canonized here.
- Retired or superseded results remain visible.
- This seed does not modify or supersede the active CRD→QCD live model.
