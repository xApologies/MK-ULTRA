# Candidate Cross-Domain Chirality Grammar

**Status:** WORKING HYPOTHESIS / NOT YET THEOREM

## Candidate skeleton

Let a domain `D` provide a state/object class `X_D`.

A chirality-bearing realization is provisionally modeled as a typed structure

`C_D = (I_D, ∂_D, χ_D, H_D, P_D, R_D)`

where:

- `I_D` — identity/address;
- `∂_D` — boundary/distinction structure;
- `χ_D` — chirality/admissibility/orientation data;
- `H_D` — dependency/history/inheritance path;
- `P_D` — persistence/provenance constraints;
- `R_D` — realized/projected/readable state.

The candidate common grammar is:

`Boundary -> Address -> Distinction -> Chirality/Admissibility -> Inheritance -> Persistence/Closure -> Realization`

## Why this candidate exists

### Prime Dependency
`0_L | 0_R` preserves identity while generating positional distinction and oriented dependency.

### Time-Space
`χ:E→Ω` assigns chirality organization; `χ(I(ξ))=τ(χ(ξ))` transports it through inheritance.

### BRANE
The `Χ` coordinate is chirality/admissibility, and the request-relative lift is representation-generating without mutating source state.

### Rainbow Road / Genesis
The full Geometric remains payload; color indexes local route; chirality determines admissible continuation; History/provenance remain on the Road.

### Atomic Profile
Atomic source organization is translated into chirality/admissibility, adjacency, persistence, closure, and recursively traversed topology.

### Fusion
Addressable null slots, boundary/interface selection, Genesis activation, gluing, witness/provenance, and new global realization are typed separately.

### CRD→QCD
The current program tests whether an upstream chirality/Road/Helicon structure produces a legitimate downstream QFT/SU(3) readout without forcing the result.

## Non-equivalence warning

The candidate does **not** assert that:
- BRANE's `Χ` coordinate is a physical pseudoscalar;
- a game-system chirality tag is the same object as field chirality;
- all `3+1+1` usages are isomorphic;
- chirality color/basin labels are QCD color.

Those are future type-audit questions.
