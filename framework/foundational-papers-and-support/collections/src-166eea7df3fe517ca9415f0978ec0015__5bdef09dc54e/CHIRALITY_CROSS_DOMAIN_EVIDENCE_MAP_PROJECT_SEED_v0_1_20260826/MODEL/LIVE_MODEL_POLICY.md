# Live Model Policy

This project inherits the lily-pad checkpoint discipline.

A **major break** is:
- a cross-domain invariant theorem;
- a no-go showing two domains are not the same type;
- a source correction/supersession;
- a new typed domain map;
- an implementation/nontriviality test closure;
- a roadmap remap;
- the final evidence-atlas verdict.

At a major break, create the next cumulative checkpoint containing:
1. roadmap and finish line;
2. active and retired claims;
3. SQLite query surface;
4. recovery prompt;
5. source hashes and authority map;
6. chronology and Vera audit;
7. machine-readable state;
8. checksums and parent reference.

Failures are lily pads, not erased branches.
