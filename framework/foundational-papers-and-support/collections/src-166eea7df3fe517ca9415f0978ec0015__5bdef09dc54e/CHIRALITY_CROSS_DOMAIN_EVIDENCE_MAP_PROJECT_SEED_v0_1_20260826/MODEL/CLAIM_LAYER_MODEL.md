# Canonical Scope and Claim Layers

## Layer E0 — Source mathematics
Definitions, axioms, theorems, typed objects, and formal source constructions.

Examples in the current corpus:
- Chirality Space `Ω`, Chirality Map `χ:E→Ω`, Chirality Transport `τ`;
- persistence/boundary/projection/residue/QFT handoff;
- Bandwidth, Resolution, History/Identity, Holonomy, Transduction;
- Prime Dependency `0|0`;
- Rainbow structural basins and Road path architecture.

## Layer E1 — Implemented computation
Executable architecture in which chirality/admissibility is an actual coordinate or decision variable.

Current example:
- BRANE 3.1 `B^6 = I×D×Χ×R×P×Z`;
- `ChiralityLift` calls `api.resolve_chirality(...)` and fail-closes on inadmissibility.

## Layer E2 — Internal model/simulation evidence
A source-defined mathematical system producing organized results inside its own environment.

Examples:
- Atomic Profile → manifold → T/R traversal;
- 108-manifold ecology;
- CRD relaxation;
- Fusion exploration.

## Layer E3 — Cross-domain structural correspondence
A proposed common grammar relating E0–E2 domains.

This is the central target of this future project.

## Layer E4 — External physical validation
Comparison with external physical observations, experiments, or independently reproduced predictions.

No E4 conclusion may be inferred merely from E0–E3.

## Governing rule

A claim may only rise to the highest layer directly supported by its evidence.
