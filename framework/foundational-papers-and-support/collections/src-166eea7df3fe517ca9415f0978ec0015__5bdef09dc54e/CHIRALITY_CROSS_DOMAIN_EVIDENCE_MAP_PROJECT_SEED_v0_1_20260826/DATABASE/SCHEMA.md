# SQLite Query Surface

Database: `chirality_evidence.sqlite3`

Tables:
- `meta`
- `roadmap`
- `domains`
- `objects`
- `claims`
- `mappings`
- `sources`
- `chronology`
- `gaps`
- `supersessions`
- `checkpoints`
- `search_index`
- `search_fts`

The database is intended to let a future AI recover the project by mathematical/domain address rather than by reading the conversation.
