# Population Contract

Every write is transactional. A package includes a canonical handle, object type, mathematical or declared non-equational identity, content blocks, provenance, package version/hash, dependency declarations, and model membership when applicable.

ADD_ONE creates one address atomically. ADD_MANY stages and commits multiple addresses atomically. ADD_PACKAGE imports a model atomically. REPLACE switches the active package beneath a stable address. REMOVE deactivates valid content. PURGE retracts an accidental admission and removes its recoverable content, aliases, relations, and indexes.
