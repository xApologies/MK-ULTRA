# Five-Dimensional Library Model

Library⁵ = (A,T,S,D,P)

- A — Address Identity: canonical handle, aliases, object/model identity, active version.
- T — Content Typing: equations, operators, definitions, theorems, proofs, derivations, models, analogies, explanations, examples, limitations, rendering blocks, provenance.
- S — Structural Placement: relation type, parent/child placement, model membership, report position, local dependency neighborhood.
- D — Recovery Depth: object, subgraph, model, or domain scope; bounded depth and continuation metadata.
- P — Provenance: archive, file, section, line range, hashes, author, import job, package version.

BRANE adds realization: QMO⁶(q)=Realize_q(A,T,S,D,P).
