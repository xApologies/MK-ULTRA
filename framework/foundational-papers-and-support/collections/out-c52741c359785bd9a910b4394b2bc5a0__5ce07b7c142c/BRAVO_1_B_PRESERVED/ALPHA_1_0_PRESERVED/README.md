# MK43 Library 1.0 Alpha

Library 1.0 Alpha is the complete implementation spine for a domain-neutral, mathematically addressed, versioned knowledge-recovery module for BRANE.

> The QMO supplies mathematical addresses. The Library returns everything encoded beneath those addresses.

This package is architecture, contracts, SQL schema, algorithms, pseudocode, migration guidance, and acceptance criteria. It is intentionally not executable production code. Its realization target is Library 1.B.

## Release progression
- Library 1.0 Alpha — implementation spine
- Library 1.B — executable realization
- Library 1.C — audit closure and finished standalone release

## Five-dimensional model
Library⁵ = (Address Identity, Content Typing, Structural Placement, Recovery Depth, Provenance)

BRANE supplies the sixth realization coordinate.

## Foundational operations
PULL, PULL_MANY, PULL_QMO, ADD_ONE, ADD_MANY, ADD_PACKAGE, REPLACE, REMOVE, PURGE, PREVIEW, COMMIT, ROLLBACK.

Recovery is exhaustive relative to the active package at an address. Summarization, translation, and truncation are downstream presentation operations.
