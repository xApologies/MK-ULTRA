## 5. Explicit tensor maps and their inverses

In a coordinate chart x^μ choose a local Genesis-side frame e_a. Write

    J(e_a) = A^μ_a ∂_μ,
    det A ≠ 0,
    B = A^{-1}.

A may depend on position. It is the local matrix of the chosen smooth realization, not a recovered numerical formula for the entire native projection.

For a vector and covector,

    v^μ = A^μ_a v_G^a,
    α_μ = B^a_μ α^G_a.

For any covariant rank-two tensor S_G, the forward and reverse maps are

    ρ_A(S_G) = Bᵀ S_G B,
    L_A(S) = Aᵀ S A.

Multiplying gives

    ρ_A(L_A(S)) = Bᵀ Aᵀ S A B = S,
    L_A(ρ_A(S_G)) = Aᵀ Bᵀ S_G B A = S_G.

These identities are exact for all ten independent components of a symmetric tensor, not just a diagonal metric. The mixed-variance formulas follow by applying A to each contravariant index and B to each covariant index.

In particular,

    g_G = Aᵀ g A,
    g_G^{-1} = B g^{-1} Bᵀ,
    T_G = Aᵀ T A.

This construction gives a genuine inverse on the tensor representation. It does not establish that a proposed g_G or T_G lies in the image of the native functions N(z).

## 6. Connection and curvature: the derivative term matters

Let Γ_μ be the coordinate connection matrix, with entries

    (Γ_μ)^ρ_σ = Γ^ρ_{μσ}.

Define C^G_μ as the connection matrix in the e_a frame while taking the derivative along the coordinate direction ∂_μ. The corresponding native frame derivative along J(e_c) has coefficients A^μ_c C^G_μ.

For a vector v = A v_G,

    (∂_μ + Γ_μ)(A v_G)
      = A [∂_μ + B Γ_μ A + B(∂_μ A)]v_G.

Consequently,

    C^G_μ = B Γ_μ A + B(∂_μ A),
    Γ_μ = A C^G_μ B − (∂_μ A)B.

The derivative of A is essential. A connection is not a tensor and cannot be translated using tensor conjugation alone.

Define curvature matrices

    Ω_{μν} = ∂_μΓ_ν − ∂_νΓ_μ + Γ_μΓ_ν − Γ_νΓ_μ,
    Ω^G_{μν} = ∂_μC^G_ν − ∂_νC^G_μ + C^G_μC^G_ν − C^G_νC^G_μ.

Apply the commutator of the two covariant derivatives to A v_G. From the connection intertwining above,

    [∇_μ,∇_ν](A v_G) = A [∇^G_μ,∇^G_ν]v_G.

Because v_G is arbitrary,

    Ω^G_{μν} = B Ω_{μν} A.

In full native frame indices,

    R_G^a_{bcd}
      = B^a_ρ A^σ_b A^μ_c A^ν_d R^ρ_{σμν}.

The quadratic connection terms are retained. Thus this is a full nonlinear transformation, not a linearized result. Tensor contractions commute with this invertible transformation:

    Ric_G = Aᵀ Ric A,
    Scal_G = Scal,
    Ein_G = Aᵀ Ein A.

For example, Ricci follows by contracting the first and third native indices and using A^μ_a B^a_ρ = δ^μ_ρ. Scalar curvature then follows using g_G^{-1} = B g^{-1} Bᵀ. There is no independent unknown nonlinear correction generated merely by writing these geometric objects in the other frame.

Parallel transport obeys the corresponding endpoint formula

    P^G_γ = B(γ(1)) P^∇_γ A(γ(0)).

The formula follows by substituting v(λ) = A(γ(λ))v_G(λ) into the parallel-transport ODE. For loops, it becomes conjugation at the base point. Geodesics, curvature acting on vectors and geodesic deviation translate using the same connection and anchor. The allowed path and variation classes must match; a native admissibility restriction can remove a target path and is not erased by these tensor identities.

## 8. What a nonfaithful readout proves instead

Let ρ denote a linear readout on field-equation residual tensors, and suppose the module's operation-preservation contract is satisfied so that

    ρ(F_G) = F_GR.

Without zero-reflection, the valid implication is

    F_G = 0  ⇒  F_GR = 0.

In the other direction one obtains only

    F_GR = 0  ⇒  F_G ∈ ker ρ.

This is an elementary proof: F_GR = 0 is exactly the statement ρ(F_G) = 0. It does not imply a zero residual before readout unless the kernel is trivial on the admitted residuals.

At the quotient residual level one may write

    [F_G]_(ker ρ) = 0  ⇔  F_GR = 0.

This says that the endpoint equation is exact after the declared quotient. It does not show that every member of that quotient class satisfies the unquotiented native equation.

This distinction is not a prohibition on noninjective History readout. A map can discard History while being faithful on the realized rank-two tensor fibers. What must be checked is faithfulness on the objects entering the field equation and compatibility of the discarded distinctions with all relevant operations.

Similarly, for any well-defined map on configurations, the quotient by equal readout is in bijection with its image. That set-theoretic fact does not prove the image is all GR, and observational equivalence is not automatically native physical gauge equivalence.

## 9. The Resolution quotient must preserve the differential information used by GR

The supplied Resolution formalism describes an algebraic congruence K_R. An algebraic quotient need not preserve derivatives, curvature or evolution.

For a derivative D acting on an algebra/module, a derivative on the quotient can be defined by

    D̄([f]) = [Df]

if and only if K_R is stable under D: representatives f and g with f−g in K_R must have Df−Dg in K_R. The proof is exactly the requirement that D̄ not depend on the chosen representative. In the general, non-additive formulation, require f ~_R g ⇒ Df ~_R Dg.

For example, evaluation at zero is a multiplicative readout of smooth functions. The function f(t)=t has zero readout, but its derivative has readout 1. Thus evaluation does not define the derivative of an equivalence class by this rule.

A geometric example is even more directly relevant. In units c=1 compare

    g_1 = diag(−1,1,1,1),
    g_2 = diag(−1,a(t)²,a(t)²,a(t)²),
    a(t)=1+k t²,

on a small interval where a>0. At t=0 the metric values and all first derivatives agree. Nevertheless

    Scal(g_1)|_(t=0) = 0,
    Scal(g_2)|_(t=0) = 12k.

The calculation is reproduced by checks.py. A readout keeping only point values or first derivatives cannot reproduce curvature in general. This is a counterexample to arbitrary coarse readout, not evidence that the actual project Q_R has this failure.

For the metric Einstein equation at a point, a sufficient local geometric record contains the relevant second-order metric derivatives (a second-order jet) plus source values and compatible coordinate transformation data. Full field theory, conservation identities, general derivative-dependent matter and solution evolution require the corresponding richer differential structure. We do not propose replacing full field information by one finite jet globally.

Thus the audit's three listed regularity conditions—curvature-limit existence, metric nondegeneracy and local source-density existence—are not by themselves a proof that a particular ρ_G has the master commutation property. Differential/transport compatibility and zero-reflection on residual tensors must also be justified or explicitly made part of the admitted smooth sector.

## 11. Source-flux refinement must be covariant

The source improvement in v1.1/v1.2 is substantive: a symmetric local tensor is associated with four-momentum flux through oriented hypersurface elements,

    dP_G^a = T_G^{ab} dΣ_b.

Existence of additive densities alone is not enough to make an arbitrary flux assignment a rank-two tensor. The local flux must depend linearly on the oriented conormal, transform covariantly between frames, possess the required regularity/absolute continuity for the chosen refinement, and have the declared symmetry. The inherited non-spin sector explicitly imposes symmetry.

Furthermore, vectors based at different spacetime points cannot in general be summed as vectors in one tangent space without a comparison/transport prescription. The finite balance law must use compatible transport or an equivalent covariant finite-volume construction. It must not be read as a globally conserved coordinate four-vector in every curved spacetime.

The correct local coordinate identity is

    ∇_μ T^{μν}
      = (1/sqrt(|g|)) ∂_μ(sqrt(|g|) T^{μν})
        + Γ^ν_{μλ}T^{μλ}.

The second term is essential. For the expanding example, the condition ∇_μT^{μ0}=0 is

    ε̇ + 3H(ε+p)=0,

or equivalently

    d(a³ ε)/dt + p d(a³)/dt = 0.

It is not, in general, d(a³ε)/dt=0. The pressure-work term is not an optional new source creation term. This calculation identifies what the finite History/momentum accounting must reproduce when taking its GR smooth limit.

The symmetric rank-two tensor translation preserves this conservation statement whenever its connection translates as in section 6. Bianchi plus a constant nonzero κ and constant Λ then makes ∇T=0 a consequence of the gravitational equation. It still does not supply every matter equation, equation of state or native stress constitutive law.

## 12. Two endpoint qualifications for the thirteen-point map

### 12.1 Null and non-affine geodesics

The displayed arc-length action is suitable for non-null curves. On a null curve the length is zero, so that expression alone is not a complete variational treatment of light rays. Length variation also yields an unparameterized geodesic unless an affine parameter is chosen.

For null curves one may use the auxiliary-field action

    S_null[γ,e] = (1/2) ∫ e^{-1} g_G(γ̇,γ̇) dλ,

on the smooth realized sector. Variation in e gives g_G(γ̇,γ̇)=0; variation in γ gives

    ∇^G_(γ̇)γ̇ = (ė/e)γ̇.

Choosing constant e gives the affine geodesic equation. This is a proposed standard endpoint clarification, not a change to native lift selection. The allowed path variations must be adequate to recover these equations.

### 12.2 Curvature from loops

For a smooth linear connection, the commutator definition of curvature is precise. A small-loop expression needs a fixed loop-orientation convention, a specified identification of fibers, and a normalization that remains meaningful for the tangent two-plane.

If u,v span a null two-plane, the metric Gram determinant can vanish even when u,v are independent. Division by an unspecified physical metric area is then not a universal formula. Also, normalizing by metric area yields curvature per unit metric area, not necessarily the unnormalized bilinear operator R(u,v).

A safe convention is a signed parameter rectangle and a fixed loop orientation:

    P_square(ε,δ) = I + σ εδ R_G(u,v) + o(εδ),
    R_G(u,v) = σ lim[(P_square−I)/(εδ)],

where σ=±1 is fixed by the orientation and parallel-transport convention, and appropriate smooth closed rectangles or corrected flow loops are used. This removes the null-area ambiguity without changing the curvature commutator convention.

The supplied finite path-defect source already says that pre-differential path dependence is not automatically a differential curvature tensor. That distinction remains in force.
