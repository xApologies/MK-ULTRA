# Brane-Only Boundary

## Identity
Brane is the host/computer mechanism.

## Included
- port interfaces and loader
- contract and integrity validation
- module lifecycle and replacement logic
- private QMO composition workspace
- request handling and artifact boundary
- tests, schemas, and architectural documentation

## Excluded
- AI implementation or payload
- API implementation or canonical mathematics
- Library implementation or archive content
- embedded copies of any plug-in module ZIP

## Mount rule
AI, API, and Library are supplied as three independent external archives. Their internal domains need not overlap. Brane validates their declared port contracts and mounts them without merging ownership or content.
