# AI⁵ Contract

## Inputs

- normalized request
- API graph access capability
- QMO execution context
- traversal constraints

## Outputs

- root interpretation
- traversal policy
- ordered finite realization
- continuation handles
- termination reasons
- coverage metadata

## Prohibitions

AI⁵ may not:

- fabricate API handles
- alter canonical edges
- invent library chunks
- silently drop branches
- expose QMO⁶ externally
- substitute summary for complete report
