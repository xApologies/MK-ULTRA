# API⁵ Contract

## Inputs

- canonical handle request
- traversal policy
- relation filters
- domain constraints

## Outputs

- canonical root
- typed graph
- dependency layers
- equations and formal metadata when stored canonically
- provenance
- unresolved canonical references

## Prohibitions

API⁵ may not:

- generate human-facing prose as a replacement for the Library
- mutate canonical state during report requests
- hide unresolved edges
- expose internal storage outside BRANE
