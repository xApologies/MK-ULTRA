# Library⁵ Contract

## Inputs

- QMO handle realization
- dependency context
- chirality context
- recursive context
- requested language and report format

## Outputs per handle

- definition
- equations
- symbol definitions
- derivations
- models
- analogies
- explanatory prose
- dependency role
- downstream implications
- provenance
- unresolved fields

## Completeness rule

A handle chunk is not complete merely because its name was returned. It must contain recoverable knowledge or an explicit unresolved record.
