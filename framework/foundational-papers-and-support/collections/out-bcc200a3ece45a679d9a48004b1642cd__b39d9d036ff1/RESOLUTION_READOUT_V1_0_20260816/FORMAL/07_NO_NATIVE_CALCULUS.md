# 7. No-Native-Calculus Rule

Resolution and Readout are defined through equivalence, quotienting, path compatibility, provenance and representation maps. No derivative or integral is required.

Smooth continuum objects may appear after readout. Examples:

```text
native transport defect  -> smooth curvature tensor
native path valuation    -> smooth arclength integral
native continuity balance -> differential conservation equation
```

The smooth expression is a downstream representation, not the substrate definition.
