# D04 — Atomic Chirality Carrier

For an atom `A`, define its Atomic Profile projection:

```text
A_A : Q_A -> X_A.
```

The Atomic Chirality Carrier is:

```text
X_A
=
(
  S_A,
  L_A,
  chi_A,
  C_A,
  a_A
).
```

Here:

```text
S_A
=
channel-valued source projection over XYZ

L_A
=
right/left chirality set lift over XYZ

chi_A
=
atom-specific chirality field

C_A
=
closure, occupancy, coupling, resistance, and environment channels

a_A
=
identity and provenance/ancestry record.
```

The supplied hydrogen, oxygen, and krypton artifacts instantiate the same
carrier type while preserving distinct channel counts and chirality fields.

The carrier is therefore common.

The organized state is species-specific.
