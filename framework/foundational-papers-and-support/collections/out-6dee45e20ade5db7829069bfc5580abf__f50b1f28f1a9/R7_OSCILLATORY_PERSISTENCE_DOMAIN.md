# R7 Oscillatory Persistence / Ecology-Readiness Domain

## Canonical Role

R7 is the final Pipeline 2 domain.

R7 exposes the manifold ecology to oscillatory persistence stress and determines whether the R6-stabilized topology remains coherent under dynamic recursive exposure.

R7 is not a new Phase 5 domain.

R7 is the final Phase 4 persistence verification domain whose outputs may later become Pipeline 3 inputs.

## R7 Inputs

R7 receives:

- R6 survivable topology state
- stabilized corridor set
- damping record
- recoverability residuals
- ancestry preservation report
- chirality occupancy record
- bandwidth occupancy record
- ordered transformation trace

## R7 Outputs

R7 emits:

- oscillatory persistence state
- oscillatory survivability score
- resonance response record
- instability onset map
- ancestry persistence score
- R7-stable manifold output
- Phase 5 readiness flag

## R7 Must Do

R7 must:

- expose topology to oscillatory persistence pressure,
- preserve valid stable topology,
- reveal invalid instability,
- preserve ancestry if recoverable,
- detect oscillatory amplification,
- detect resonance-like instability,
- pass stable outputs forward as ecology-ready structures.

## R7 Must Not Do

R7 must not:

- redefine topology,
- create new corridor candidates,
- overwrite R5 resolution,
- rewrite chirality,
- hardcode element outcomes,
- act as a new Phase 5 system.

## R7 Pass Criteria

A topology passes R7 when:

- ancestry remains recoverable,
- coherence remains bounded,
- corridor set does not runaway expand,
- valid resolved topology remains stable,
- oscillatory exposure does not create artificial collapse,
- instability, if present, is explainable through recorded residuals.

## R7 Failure Criteria

R7 fails a topology when:

- valid topology disassembles without explainable perturbation cause,
- ancestry becomes unrecoverable,
- oscillation creates runaway corridor proliferation,
- R6-stabilized topology is arbitrarily overwritten,
- R7 produces new element-specific behavior.
