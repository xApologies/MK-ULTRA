# A01 — Author Profile Package

**Input:** user/caregiver/qualified-team requirements.  
**Output:** candidate structured `ProfileDefinitionPackage`.

1. Collect explicit sensory preferences, protected cues, unacceptable transforms, context constraints, and approvals.
2. Represent unknowns as unknowns.
3. External authoring AI may normalize prose into schema fields but may not invent clinical facts.
4. Validate package schema.
5. Generate provenance receipt and content fingerprint.
6. Submit candidate package to BRANE construction request.
