# Build Phases

## Phase 0 — Genesis Point archaeology
Recover prior headphone architecture and reconcile terminology.

## Phase 1 — SPO API Alpha
Build canonical mapped auditory object, schemas, event handles, transform handles, admissibility/provenance, and test fixtures.

## Phase 2 — BRANE adapters
Implement auditory AI^5/API^5/Library^5 packages that pass BRANE contracts.

## Phase 3 — Independent SPO projection
Implement `π_SPO`, fingerprinting, versioning, and policy compiler.

## Phase 4 — Offline simulation
Feed labeled acoustic-event traces through the policy engine and Vera gate. No live audio required.

## Phase 5 — Live non-clinical DSP prototype
Integrate a hardware-agnostic audio backend and instrument latency/power.

## Phase 6 — Human factors / accessibility research
Define outcomes with appropriate experts and users. Validate safety and usability.

## Phase 7 — Clinical track if pursued
Separate protocol, qualified investigators, ethics/regulatory review, and external validation.
