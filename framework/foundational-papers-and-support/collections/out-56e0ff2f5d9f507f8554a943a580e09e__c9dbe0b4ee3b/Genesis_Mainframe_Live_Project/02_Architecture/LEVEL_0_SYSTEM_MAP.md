## One complete transaction

```text
1. Physical power maintains the basin substrate.
2. The persistent store exposes a chirality-organized region.
3. The operating topology instantiates a Geometric.
4. Guardian interprets purpose and constraints.
5. The transformation fabric applies admissible Genesis operators.
6. A portal transfers the Geometric when relocation is required.
7. The destination closes into a recoverable identity.
8. Guardian verifies the result.
9. The recovered result becomes inherited state.
```

## Key interface boundaries

```text
Energy <-> Basin Device
Basin Device <-> Chirality Cell
Chirality Cell <-> Recursive Fabric
Fabric <-> Geometric
Geometric <-> Genesis Operator
Operator <-> Portal
Operating Topology <-> Guardian
Guardian <-> Human/Application
```

Each boundary requires a formal contract before hardware can be designed coherently.
