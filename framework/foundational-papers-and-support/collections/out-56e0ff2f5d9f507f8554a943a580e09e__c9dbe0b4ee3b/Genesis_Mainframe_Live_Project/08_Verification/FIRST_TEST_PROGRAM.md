# First Verification Program

The first laboratory research program should test the substrate, not pretend to build the whole mainframe.

## Test family A — Basin device

- establish six distinguishable states;
- measure read/write distributions;
- measure drift and retention;
- measure thermal behavior;
- identify guard bands.

## Test family B — Chirality tile

- arrange cells in a `2 x 2 x 2` tile;
- instantiate RIGHT and LEFT;
- verify mirror conversion;
- verify arrangement recovery after serialization/readout;
- measure local cross-talk.

## Test family C — Native operations

Implement candidate physical or microarchitectural forms of:

```text
inherit
propagate
stabilize
redistribute
close
normalize
```

## Test family D — Portal transfer

- define two fabric regions;
- transfer one Geometric;
- verify identity and provenance;
- force insufficient Bandwidth;
- force insufficient Resolution;
- verify rejection rather than silent corruption.

## Test family E — Guardian supervision

Use a non-native research AI initially to:

- inspect state;
- identify inadmissible operations;
- route a portal;
- verify closure;
- explain the result.

The research AI is a development instrument, not yet the final Guardian.
