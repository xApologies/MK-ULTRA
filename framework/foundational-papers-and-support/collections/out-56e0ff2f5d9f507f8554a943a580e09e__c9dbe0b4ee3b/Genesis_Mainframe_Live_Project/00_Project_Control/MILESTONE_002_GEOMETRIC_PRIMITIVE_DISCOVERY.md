# Milestone 002 — Geometric Primitive Discovery

**Date:** 2026-08-03  
**Status:** Active working model  
**Scope:** Genesis language discovery

## Current architectural recognition

The Genesis programming language is not being derived from conventional primitive types such as:

```text
integer
floating point
character
string
boolean
```

The current candidate native primitive is:

```text
Geometric
```

A Geometric is provisionally understood as a populated `3+1+1` chirality-organized manifold.

The smallest concrete local structure currently under examination is a colored `2 x 2 x 2` chirality byte.

## Important status boundary

This is not yet a locked programming-language specification.

The project is still discovering:

```text
what a Geometric is
what information it carries
what transformations are native
what the portal must transport
what color means computationally
what the Guardian must infer
what the hardware must expose
```

Syntax, loops, functions, variables, and other conventional language features remain undecided.

## First stable insight

A chirality byte may have:

1. an occupancy/chirality arrangement;
2. a local basin value at every occupied site;
3. an aggregate byte-level color derived from the internal energy-density arrangement;
4. a full internal composition that remains distinguishable even when two bytes resolve to the same aggregate color.

This is the first serious candidate for Genesis-native data organization.
