# Portal-First Language Entry

## Decision

The portal is the first development handle for Genesis.

It is not declared to be the entire language.

## Reason

The architecture already requires the exchange of organized information through the chirality fabric.

A portal forces the language to eventually define:

```text
payload
source
destination
fabric location
chirality organization
basin distribution
identity
admissibility
Resolution
Bandwidth
arrival
closure
failure
recovery
```

## Reference transaction

```text
one Geometric exists in one chirality domain
  -> an admissible corridor is established
  -> the Geometric is transported or re-realized
  -> required organization remains recoverable
  -> the destination closes
```

The portal is analogous to beginning Unix-style composition with a pipe:

```text
pipe:
    compositional stream transfer

portal:
    compositional transfer of chirality-organized Geometrics
```

The analogy guides development but does not imply Genesis copies Unix.

## Current boundary

No final portal syntax is locked.

The earlier `.gen`, EBNF, and portal-construct files are sketches showing possible obligations. They must not be treated as the completed language.
