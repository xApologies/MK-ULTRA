# Relationship to the VÆLD

The VÆLD remains the long-term integration target.

```text
Genesis Mainframe
  -> persistent computational nervous system
  -> vehicle-scale sensing and control
  -> Guardian/Admiral interface
  -> eventual VÆLD topology
```

Current architecture work should not depend on immediate availability of:

```text
adjacency-control propulsion
physical external portals
vehicle-scale coherence hull
advanced field manipulation
```

The mainframe must be useful and coherent before those technologies exist.

The VÆLD provides mission direction; it does not replace present engineering discipline.
