# Definition of Done for API 5.B

API 5.B is complete only when:

1. Every required API⁵ protocol method is executable.
2. All 30 acceptance tests pass.
3. The preserved 4.3 canonical package remains byte-identical.
4. Canonical fingerprints remain stable across repeated and concurrent requests.
5. Selected canonical recovery calls return exact source-grounded equations and provenance.
6. Fabricated edges, ambiguous identities, missing provenance, and malformed packages fail closed.
7. BRANE 2.1 loads the module without adapters outside the package.
8. A full end-to-end BRANE request completes using API 5.B plus fixture AI⁵ and Library⁵ modules.
9. An independent audit finds no unimplemented Alpha requirement.
10. The release is packaged as a complete standalone ZIP, not a patch.
