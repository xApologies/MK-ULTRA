# Compatibility Policy

- 4.3 handles remain valid.
- 4.3 typed edge records remain valid.
- Existing provenance strings remain unchanged.
- Existing registries remain authoritative within their declared scope.
- API 5.B may create new indexes only as reproducible derived artifacts.
- New canonical material must be appended through a separately versioned recovery pass, not inserted by runtime execution.
- BRANE compatibility is governed by contract version `2.0`.
