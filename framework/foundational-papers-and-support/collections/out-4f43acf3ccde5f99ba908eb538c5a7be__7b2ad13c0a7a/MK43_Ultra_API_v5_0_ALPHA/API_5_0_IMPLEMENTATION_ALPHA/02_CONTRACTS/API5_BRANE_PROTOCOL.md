# BRANE 2.1 API⁵ Protocol

```python
class API5(Module5Base):
    contract_version = "2.0"
    internal_dimension = 5
    canonical_state_policy = "READ_ONLY"
    rewrite_policy = "DERIVED_ONLY"

    def dimension_model(self) -> dict[str, bool]: ...
    def fork_request_context(self) -> "API5": ...
    def canonical_fingerprint(self) -> str: ...
    def healthcheck(self) -> bool: ...

    def resolve(self, subject: str) -> str: ...
    def neighbors(self, handle: str, direction: TraversalDirection) -> Sequence[EdgeRecord]: ...
    def recover_closure(self, root: str, intent: RecoveryIntent) -> CanonicalGraph: ...
    def recover_equations(self, handle: str) -> Sequence[str]: ...
    def recover_provenance(self, handle: str) -> Sequence[str]: ...
    def resolve_chirality(self, node: TraversalNode, intent: RecoveryIntent,
                          provenance: Sequence[str]) -> str: ...
    def admissible(self, node: TraversalNode, intent: RecoveryIntent,
                   chirality: str, provenance: Sequence[str]) -> bool: ...
    def validate_graph(self, graph: CanonicalGraph) -> None: ...
```

## Behavioral requirements

- `resolve` never fabricates a handle.
- `neighbors` returns only direct canonical edge records for the requested direction.
- `recover_closure` retains composed paths as paths; it never promotes them to direct edges.
- `recover_equations` preserves exact source mathematics and ordering.
- `recover_provenance` is object-specific, not root-wide.
- `resolve_chirality` is deterministic for identical canonical state and intent.
- `admissible` returns false for unsupported or provenance-free continuations.
- `validate_graph` fails closed.
