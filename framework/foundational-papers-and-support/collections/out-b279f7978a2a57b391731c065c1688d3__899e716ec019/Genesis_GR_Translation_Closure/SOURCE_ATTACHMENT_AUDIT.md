## Admission behavior

The executable model accepts evaluated smooth records and checks several exact local algebraic/differential conditions. Declared smoothness, signature, global domain and source origin remain explicit assumptions or externally supplied evidence. It does not authenticate provenance.

A raw dictionary of native variables is not converted by inventing a target metric. `attach_raw_native_state` raises an explicit unsupported-attachment exception. The negative test verifies that behavior. It is not counted as evidence that an actual native inverse does or does not exist.

## Why the full endpoint cannot be certified by this run

To certify it, the same actual native state must produce the required metric, selected transport, flux density and retained fields, satisfy its native constraints, and be physically recoverable from the complete translated description. This run has not constructed that state or proved general coverage/physical uniqueness.

No extra physical gauge relation was defined. No target GR solution was labelled “native” merely by attaching native names. No source tensor was defined as the Einstein residual divided by a coupling. The symmetric flux inputs in the tests are explicitly constructed test data, not recovered native physics.

This is the specific remaining unresolved boundary, not another open-ended list of unrelated foundational tasks.
