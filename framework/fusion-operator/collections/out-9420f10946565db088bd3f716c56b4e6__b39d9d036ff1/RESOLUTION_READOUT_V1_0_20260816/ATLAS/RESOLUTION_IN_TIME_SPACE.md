# Atlas Integration — Resolution in Time-Space

Current Atlas ordering:

```text
Genesis Field
  -> Time-Space
  -> Resolution
  -> Bandwidth
  -> Chirality
  -> Persistence
```

The Time-Space architecture supplies formal/localized domains. Resolution determines which organization in those domains is distinguishable. Bandwidth then restricts which transformations/configurations remain operationally available.

For a localized spacetime address `Sigma_p`, define its Resolution-conditioned readable state schematically as

```text
Sigma_p^R := Read_R(Sigma_p).
```

This should not be read as the physical sphere itself changing because an observer "zooms." It is the accessible/readable equivalence structure at that Resolution.

The local QFT/GR/ER-foam representations must therefore inherit an explicit Resolution index whenever the distinction matters:

```text
QFT_p^R
GR_p^R
ER_p^R.
```

This makes Resolution a formal part of the Atlas rather than a visual metaphor.
