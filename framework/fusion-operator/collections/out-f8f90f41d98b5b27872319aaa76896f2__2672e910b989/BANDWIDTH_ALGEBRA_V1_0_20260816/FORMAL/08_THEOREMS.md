# 8. Lemmas and Theorems

## BA-L1 — Restriction Cannot Create Formal Transformations

If `A_B' -> A_B` is a pure Bandwidth restriction inclusion, every transformation in `A_B'` already belongs to `A_B`.

Therefore pure restriction cannot create a new formal corridor.

## BA-L2 — Resolution Can Identify Distinct Formal Transformations

If `rho_R` is non-injective, there may exist `a != b` with `rho_R(a)=rho_R(b)`.

Thus observational equality does not imply formal equality.

## BA-L3 — Compatible Readout Preserves Composition

If `rho_R` is composition-preserving, then:

```text
rho_R(b o a) = rho_R(b) o rho_R(a).
```

## BA-T1 — Cross-Resolution Bandwidth Persistence

For fixed formal `A_B` and compatible Resolution family `{rho_R}`, every observational algebra `A_B^R` is a Resolution-dependent image of the same formal Bandwidth object.

Therefore one Bandwidth may persist across multiple Resolutions.

## BA-T2 — Hidden Formal Corridor Theorem

Distinct formal corridor words may have one coarse Resolution image. Hence a coarse observable path may conceal multiple formal histories.

## BA-T3 — Saturation Characterization

At state `x`, operative Bandwidth is saturated iff no non-identity generator is available:

```text
Sat_B(x) <=> Free_B(x)=empty.
```

The identity state can remain persistent under saturation.

## BA-T4 — Bandwidth/Resolution Independence

A Resolution change alone does not add a formal transformation to `A_B`; a Bandwidth expansion can add a formal transformation without changing Resolution.

Therefore distinguishability and capacity are formally independent axes.

## BA-T5 — Persistence Is Not Necessarily Scalar Bandwidth Loss

If a persistence modifier both removes incompatible generators and stabilizes new reliable composites, there is no universal scalar law `B_after < B_before` without a declared valuation.

Thus the source statement “stable structures may reduce freedom while increasing coherence” is mathematically consistent.

## BA-T6 — Corridor Availability Theorem

A typed corridor from `x` to `y` exists in Bandwidth state `B` iff there exists at least one composable operator word in `A_B` with source `x` and target `y`.

## BA-T7 — Geometry Readout Provenance

For `Geo_R(B)=Spec_T(A_B/K_R)`, every readable geometric feature with a valid provenance witness descends from a formal Bandwidth class. Resolution may merge formal classes but does not create a new formal transformation.
