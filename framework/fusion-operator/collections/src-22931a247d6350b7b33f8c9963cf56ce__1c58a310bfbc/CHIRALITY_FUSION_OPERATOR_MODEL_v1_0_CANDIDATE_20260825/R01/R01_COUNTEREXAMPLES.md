# R01 — Counterexample Ledger

## CE-01 — Null/existence label mismatch

Use the same mirror seeds

\[
L=
\begin{bmatrix}
E&N\\
N&E
\end{bmatrix},
\qquad
R=
\begin{bmatrix}
N&E\\
E&N
\end{bmatrix}.
\]

Select

\[
\ell_{12}\mapsto r_{12}.
\]

Then

\[
\lambda_L(\ell_{12})=N,
\qquad
\lambda_R(r_{12})=E.
\]

The R01 null-interface template requires `N ↔ N`. Therefore the label map cannot descend under the R01 fusion typing without adding a separate label-merger rule.

Verdict:

\[
A_F^{NN}=0,
\qquad
\mathfrak F^{NN}_0=\text{undefined}.
\]

A bare set quotient can still be formed. That is exactly why **set quotient existence is not sufficient for typed fusion**.

## CE-02 — Gluing without Fusion activation

Take a valid `N ↔ N` interface and construct the quotient \(Q\), but omit \(\eta_F\).

Then:

\[
Q_\rho(C_A,C_B)
\]

is a valid raw glued carrier, but the R01 Fusion Operator has not been applied.

Verdict:

\[
\textsf{Glue defined},
\qquad
\textsf{Fusion undefined}.
\]

This prevents the word *fusion* from becoming a synonym for ordinary adjacency or quotient identification.

## CE-03 — No boundary eligibility

Choose a locus not admitted by \(\partial V_A\) as the interface.

The required interface embedding

\[
i_A:J_N\hookrightarrow\partial V_A
\]

does not exist.

Verdict: outside the domain of contact Fusion.

## CE-04 — Placement without contact

Take compatible mirror seeds and null labels but a placement \(\rho\) for which:

\[
\mathrm{Adj}_\rho(i_A(j),i_B(j))=0.
\]

The current **contact** operator is undefined.

This does not prove that every possible nonlocal fusion operator is impossible. It only blocks silent generalization beyond R01.

## CE-05 — Formal fusion exists; operative fusion does not

Suppose the R01 formal conditions are satisfied, but the active Bandwidth Algebra lacks the required fusion transformation:

\[
f_\rho\notin A_B.
\]

Then the formal object exists, while operative execution at \(B\) is unavailable.

This is a counterexample to:

> "If an operation is mathematically admissible, it is always operationally available."

---

## CE-06 — Readout invisibility is not nonexistence

Suppose a coarse Resolution \(R_c\) identifies the fused and unfused readable presentations:

\[
\rho_{R_c}(F_\star)
=
\rho_{R_c}(Q_\star).
\]

This does not imply

\[
F_\star=Q_\star
\]

as formal objects.

It is a counterexample to:

> "If Fusion cannot be distinguished at the current Resolution, Fusion did not occur."

## CE-07 — Same visual center does not prove same fusion provenance

Two different seed pairs can, in principle, produce the same rendered central marker while carrying different tagged provenance records.

Therefore endpoint appearance or a green central glyph is not a sufficient Fusion Witness.

This protects the roadmap against turning the source sketch into self-authenticating proof.
