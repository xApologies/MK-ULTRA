# R07 — Counterexample Ledger
## Chirality Conservation

### CE7-01 — Zero net does not mean zero chirality
For an opposite pair,

\[
S_\chi=0
\]

while

\[
C_\chi=2.
\]

Therefore scalar cancellation cannot establish annihilation.

### CE7-02 — Equal population does not imply equal chirality
Mirror seed orientations can have identical occupancy counts while differing in arrangement/handedness. Population conservation is therefore weaker than chirality conservation.

### CE7-03 — Null interface is not chirality zero
`q` is null-labeled in the set/state layer. Chirality is an organizational relation. Assigning `chi(q)=0` without a pointwise chirality field is a type error.

### CE7-04 — Bare-carrier symmetry does not erase local chirality
An involution may exchange the two opposite-handed source images while fixing the fused interface. A mirror-self-isomorphic global carrier can therefore contain nontrivial local chirality.

### CE7-05 — Source swap is not provenance equality
The bare quotient may satisfy

\[
Q(A,B)\cong Q(B,A),
\]

while the ordered Fusion witness distinguishes which source occupied which historical role.

### CE7-06 — `LL`/`RR` arithmetic is not a Fusion result
Writing signed totals `+2` or `-2` for hypothetical same-handed pairs does not prove those pairs belong to the current Fusion domain. The current operator is undefined on those inputs unless explicitly extended.

### CE7-07 — One-sided mirror is not a conservation failure
Mirroring one source changes the input opposition class from `Pi_chi=-1` to `Pi_chi=+1`. Under the current operator that is an admissibility failure/new input class, not evidence that Fusion changed chirality.

### CE7-08 — Quantum expectation is not structural conservation
A quantum state may have zero expectation value of a chosen chirality observable while retaining coherent or entangled structure. That does not replace the carrier/source chirality profile derived here.

### CE7-09 — Additive scalar is insufficient for provenance
`LR` and `RL` both give signed net zero. The scalar cannot distinguish source order, path, seam, or witness ancestry.

### CE7-10 — Interface relation does not create a third handedness automatically
The existence of `eta_F` or of the shared quotient class does not, by itself, define an emergent handed class for the composite. Such an emergent chirality would require a separately derived operator/observable.
