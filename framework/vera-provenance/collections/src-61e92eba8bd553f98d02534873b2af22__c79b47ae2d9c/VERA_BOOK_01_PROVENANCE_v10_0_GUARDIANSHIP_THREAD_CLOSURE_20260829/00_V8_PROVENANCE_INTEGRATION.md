# V8 — Provenance-specific integration

Provenance is extended from source lineage into **question lineage**: a result may require provenance not only of objects and sources, but of the question that made the result visible.

New standing query:

\[
\boxed{\text{What question made this object mathematically available?}}
\]

A locally primitive symbol or object must be able to point backward to its admission or construction record when foundational Resolution is requested.
