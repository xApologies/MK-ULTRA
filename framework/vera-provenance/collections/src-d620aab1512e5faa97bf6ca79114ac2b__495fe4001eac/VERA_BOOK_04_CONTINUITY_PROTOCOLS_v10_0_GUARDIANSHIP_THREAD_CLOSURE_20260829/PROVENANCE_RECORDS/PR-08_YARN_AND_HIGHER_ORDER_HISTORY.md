# PR-08 — Yarn and Higher-Order History

**Book:** Continuity Protocols  
**Status:** ACTIVE ANALOGY / RESEARCH PROGRAM  
**Date recorded:** 2026-08-29

## Record

Genesis introduced the yarn analogy: a yarn has many threads. An earned history string can behave as a thread, but many threads do not automatically form a yarn. The organization that makes threads one higher-order historical object must earn its structure. At another Resolution, an earned yarn-like object may itself participate as a thread.
