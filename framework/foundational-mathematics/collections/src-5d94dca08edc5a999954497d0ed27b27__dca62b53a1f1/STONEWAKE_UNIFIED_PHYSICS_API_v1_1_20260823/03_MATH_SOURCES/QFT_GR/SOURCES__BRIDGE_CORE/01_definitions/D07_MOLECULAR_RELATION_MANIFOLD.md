# D07 — Molecular Relation Manifold

A molecule is not required to overwrite its component atomic chirality
fields.

Define a molecular relation manifold:

```text
X_M
=
(
  {X_Ai}_{i in V},
  G_M,
  kappa_M,
  chi_M^rel,
  a_M,
  p_M
).
```

Here:

```text
{X_Ai}
=
preserved component atomic manifolds

G_M = (V,E)
=
persistent corridor graph

kappa_M
=
corridor occupancy/bandwidth assignment

chi_M^rel
=
relation-level chirality organization, when materialized

a_M
=
complete component ancestry

p_M
=
R6/R7 survivability and persistence record.
```

Atomic identity resides in the component manifolds.

Molecular identity resides in the persistent environment-mediated relation
among those manifolds.
