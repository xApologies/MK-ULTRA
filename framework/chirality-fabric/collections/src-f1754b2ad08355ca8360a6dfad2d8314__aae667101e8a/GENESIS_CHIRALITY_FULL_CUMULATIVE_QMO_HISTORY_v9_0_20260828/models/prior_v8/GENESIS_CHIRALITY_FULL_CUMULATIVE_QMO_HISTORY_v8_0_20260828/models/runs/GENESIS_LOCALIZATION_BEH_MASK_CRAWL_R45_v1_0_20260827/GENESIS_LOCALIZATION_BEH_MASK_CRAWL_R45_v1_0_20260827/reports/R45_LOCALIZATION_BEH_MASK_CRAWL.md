## Source-derived localization ingredients

### Environment Address Space

The Unified API defines:

`A_E`

as the QMO-local set of admissible Environment addresses where:

- inherited organization;
- chirality;

- Bandwidth;

are jointly readable.

This is exactly the local state-space interface R44 needed.

### Time Shell / Persistent Boundary

The Time Shell is source-defined as a dynamic persistent-boundary / projection interface through which boundary organization becomes readable.

Sustained temporal continuity begins downstream of the pre-Time-Shell regime.

The Persistent Boundary is the canonical interface between persistent organization and the surrounding inherited Environment.

So localization is explicitly a boundary/interface operation rather than an upstream arbitrary choice.

### Projection Admissibility

The Unified graph types `@projection_admissibility` upstream from the Persistent Boundary.

### Boundary Projection and residue

The source gives:

`Pi : dXi -> M`

and says invariant residue is retained.

It also gives:

`F_p = Inv(Pi^{-1}(p))`.

Therefore admissible localization cannot discard a required invariant residue.

### Occupancy

The source's promoted Occupancy object is:

> the actually realized object/section among supportable possibilities.

That means occupancy belongs downstream of supportability/admissibility, not upstream as a selector of arbitrary formal possibility.

## Derived mask factorization

For a formal candidate lift `lambda`, define only at the **typing level**:

`M_loc(p,lambda)=1`

iff all source-typed clauses pass:

1. `lambda` is represented at an admissible local Environment address in `A_E`;
2. inherited organization, chirality, Resolution, Bandwidth and recursive ordering are jointly readable there;
3. `lambda` is compatible with the persistent-boundary / Time-Shell localization interface;
4. projection admissibility passes;
5. local Bandwidth supports the transformation;
6. retained orientation/relational History and recursive inheritance remain compatible;
7. occupancy/localized-realization constraints pass;
8. required invariant residue survives projection.

Then:

`L_oper(p) = {lambda in L_formal(p) : M_loc(p,lambda)=1}`.

This is the source-backed replacement for the shorthand `M_BEH(p)`.

## Important closure

The mask is **not a preference function**.

It is an intersection of admissibility predicates.

That preserves the architecture:

`formal availability`
-> `localization mask`
-> `operative lift family`
-> `Watcher`
-> selected lift or legitimate residual tie.
