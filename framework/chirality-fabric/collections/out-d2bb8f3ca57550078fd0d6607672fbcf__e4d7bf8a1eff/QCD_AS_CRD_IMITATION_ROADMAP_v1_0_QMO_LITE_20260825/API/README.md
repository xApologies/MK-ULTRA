# QMO-Lite API

Examples:

```bash
python API/mini_qmo_api.py recover "imitation"
python API/mini_qmo_api.py recover "Pi_YM"
python API/mini_qmo_api.py neighbors "Yang-Mills"
python API/mini_qmo_api.py roadmap
python API/mini_qmo_api.py open
python API/mini_qmo_api.py search "glueball"
```

The API recovers the immediate local mathematics and status.
It does not infer missing bridge maps.
