# C04 — Imitation Contract
**Verdict: PASS — FORMAL**

Defined exact imitation by the commuting condition:

`Pi_YM o R_CRD = R_YM o Pi_YM`.

`D_imit(X) = d_O(Pi_YM(R_CRD(X)), R_YM(Pi_YM(X))) <= epsilon`.
