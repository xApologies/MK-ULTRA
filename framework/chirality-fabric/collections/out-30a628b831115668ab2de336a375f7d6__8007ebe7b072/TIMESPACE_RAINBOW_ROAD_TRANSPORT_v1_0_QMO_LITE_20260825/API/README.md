# QMO-Lite API

Examples:

```bash
python API/mini_qmo_api.py recover "rainbow road"
python API/mini_qmo_api.py neighbors qmo://timespace/rainbow-road
python API/mini_qmo_api.py recover qmo://timespace/transport/U_Q
python API/mini_qmo_api.py search "naturality"
python API/mini_qmo_api.py roadmap
python API/mini_qmo_api.py open
```

The API is only a lightweight recovery/navigation layer.

It does not infer missing physics and does not turn graph reachability into proof.
