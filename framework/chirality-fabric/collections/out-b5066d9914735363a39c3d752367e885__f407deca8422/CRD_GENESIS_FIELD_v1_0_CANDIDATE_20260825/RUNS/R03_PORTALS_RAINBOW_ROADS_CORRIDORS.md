# R03 — Portals, Rainbow Roads, and Corridor Admissibility
**Verdict: PASS**

CRD separates constraint events `E_g` from spontaneous relaxation Portals `P_S`.

A Rainbow Road is `gamma = E_g ; P_S1 ; ... ; P_Sn`.

Each relaxation segment explicitly checks chirality update, fixed seam-sector residue, ancestry/provenance, Resolution, Bandwidth, membership in `C_G`, and strict potential descent. Final Road closure is a persistent/global-minimum state.

Missing event witness, insufficient R/B, missing invariant/provenance, illegal target, or missing closure target are deterministic failures.

Strict relaxation Roads cannot cycle on a finite state space.

**Exit gate:** PASS.
