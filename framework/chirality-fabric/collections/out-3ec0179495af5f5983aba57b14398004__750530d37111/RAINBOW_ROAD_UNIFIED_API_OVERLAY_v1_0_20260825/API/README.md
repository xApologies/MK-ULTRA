# Overlay API

After unzipping:

```bash
python API/overlay_api.py roadmap
python API/overlay_api.py coverage
python API/overlay_api.py overlay "Rainbow Road"
python API/overlay_api.py bindings "Helicon"
python API/overlay_api.py native @helicon
python API/overlay_api.py neighbors @helicon
python API/overlay_api.py road-to @higgs_field
python API/overlay_api.py road-to @dm_source_er_effective_model_closure
python API/overlay_api.py road-to @gravity --directed
python API/overlay_api.py six-to-three
python API/overlay_api.py open
```

`road-to` begins from the native parent handles that type the Rainbow-Road contract.

Navigation paths may reverse parent edge direction and report that explicitly. Navigation is not proof.

Use `--directed` when direction matters.
