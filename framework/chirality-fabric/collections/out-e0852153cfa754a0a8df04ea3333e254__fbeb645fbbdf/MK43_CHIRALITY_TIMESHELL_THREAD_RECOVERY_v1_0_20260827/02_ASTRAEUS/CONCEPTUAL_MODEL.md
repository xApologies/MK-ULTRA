# Current Conceptual Model

## Chirality is the water
The current simple analogy maps **chirality itself** to water. It is the common organizational medium/grammar, not a downstream object added onto already-realized spacetime.

A Time Shell is a persistently maintained local organization/phase of chirality. Multiple Time Shells can coexist and interact inside one larger chirality field while remaining separately persistent.

## Two-shell water/ice state
- `TS_W`: liquid-water organization, one Time Shell.
- `TS_I`: ice organization, another Time Shell.
- Both are chirality; they differ by persistent organization/state.
- They interact at an interface; they are locally distinguishable but not dynamically isolated.

## CRD relaxation
CRD changes the local organization of the ice shell. When the ice's separately persistent distinction can no longer be maintained, the ice shell ceases to exist as a distinct shell and becomes compatible with the water shell:

`TS_W + TS_I  --interaction/CRD-->  TS_W'`

Shell count: `2 → 1`. Chirality is not destroyed; the separately persistent organization is.

## Complex realized objects
Human, tree, cat, chair, rock, etc. are current conceptual examples of much more complicated Time-Shell organizations within the larger chirality field. Their local configuration spaces can support continuous post-T5 chirality updates. Complexity belongs in configuration, recursion, history, Resolution/Bandwidth and persistence—not in multiplying foundational substances.

## Cosmology / consciousness
The direct API `@cosmology → @consciousness` edge remains source-attested. The current candidate semantic interpretation is not causation but **ambient-domain/support-of-realization**: spacetime/cosmology is the realized domain within which localized conscious organization can exist. Exact relation typing remains unresolved.

## Motto
**Simple. Elegant. Sophisticated.**

The goal is to keep primitives and explanations simple enough that recursion does not create uncontrolled conceptual complexity. Sophistication should emerge from composition and recursion, not from unnecessary primitive inflation.
