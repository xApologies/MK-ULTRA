## What this package is

This is the first cumulative formalization checkpoint for **Genesis** as a mathematical discipline grounded in Genesis Language. It is intentionally **language-first and proof-first**, not CRD/QCD-first. The CRD→QCD `Λ_HQ` problem appears only as a downstream stress test.

The project uses the Time-Space `00–05 + _PRIME` files as construction templates: primitives must earn necessity/minimality; definitions state exact scope; axioms isolate irreducible assumptions; lemmas prove local consequences; theorems assemble major results; interfaces remain typed and auditable.

## Critical discipline

Genesis is **not declared a new branch of mathematics by fiat**. The package builds the formal object, compares it against established structures, and preserves a novelty ledger. “New branch” remains a research verdict.

## Core source sentence

Genesis Language is relationship-first. The formal program therefore centers **boundary, relationship, identity, persistence/history, scope, resolution, and witnessed realization** rather than beginning from an arbitrary manifold, graph, field, or algebra.

## Canonical firewalls

- same symbol ≠ same object;
- same endpoint ≠ same history;
- same readout ≠ same formal identity;
- representation ≠ whole-object identity;
- dependency ≠ causation;
- similarity ≠ equivalence;
- readout may merge distinctions but does not create them;
- target structure is not source-derived without a witness;
- failed branches are retained.

This package closes the **foundational pass**, not the imagined final multi-thousand-page publication edition. It is deliberately cumulative and designed to grow. Open conjectures and novelty questions remain explicitly open.
