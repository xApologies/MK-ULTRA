# VERA PEN PROTOCOL

A playful audit vocabulary based on the requested colored pens. The colors are workflow labels, not physical or epistemic truth values.

- **RED** — fatal contradiction / proved no-go / invalid type use. Must rollback or supersede.
- **ORANGE** — major typing/descent/composition debt; object may not be used downstream as if closed.
- **YELLOW** — ambiguity, multiple candidate realizations, unresolved scope, or missing source witness.
- **GREEN** — local definition/lemma/theorem closed under stated hypotheses.
- **BLUE** — provenance, source hash, authority, and dependency lineage verified.
- **VIOLET** — cross-model/cross-book compatibility verified without category collapse.
- **BLACK** — quarantined/superseded/historical branch. Preserved but forbidden from silently returning to operative canon.

A formal item may carry several pens simultaneously, e.g. GREEN proof + BLUE provenance + YELLOW novelty classification.
