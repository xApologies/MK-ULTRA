# Next Hack: Superposition / Continuous Rainbow Resolution

The clean failure of six-state midpoint closure may be a Resolution problem rather than an algebra failure.

Key examples:
- `R|O -> 1.5`
- `R|V -> 3.5`

Historical default was truncation in some contexts, but compare four models without calculus:
1. Truncation model — map half-step to lower basin.
2. Pair-superposition model — retain `1.5` as `R/O`, `3.5` as `Y/G`, etc.
3. Dyadic Resolution model — recursively refine basin addresses through repeated midpoint construction.
4. White carrier model — treat White as the superposed structural carrier from which coarse basin readouts resolve.

Tests:
- preserve ordered Cradle orientation;
- preserve `ρ²=id`;
- compare commutativity of readout vs order-sensitivity of carrier;
- test recursive closure and periodic orbits;
- test whether coarse Resolution is a quotient of a finer continuous/dyadic carrier;
- avoid importing SU(2);
- only after the internal algebra is complete, test whether any natural two-component complex representation exists.
