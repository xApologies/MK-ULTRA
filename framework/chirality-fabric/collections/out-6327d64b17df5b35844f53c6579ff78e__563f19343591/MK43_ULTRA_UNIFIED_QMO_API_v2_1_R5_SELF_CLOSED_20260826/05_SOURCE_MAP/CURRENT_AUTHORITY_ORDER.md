# Authority / traversal policy

1. Exact source records and their source-specific authority/status remain authoritative within their declared scope.
2. Existing parent QMO/API records are imported without promotion.
3. New v2 source-root, mount, shared-handle, and document-mention links are navigation/provenance only.
4. A route through the graph is not automatically a composed theorem.
5. Conflicts are preserved as parallel namespace instances unless a source-authoritative supersession record resolves them.
