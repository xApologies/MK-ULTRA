# QMO Mini API

Canonical database: `../database/genesis_closure_qmo.sqlite`

Run:
```bash
python api/qmo_api.py
```

Default endpoint: `http://127.0.0.1:8765`

Examples:
- `/qmo/cradle`
- `/qmo/V4`
- `/qmo/V4/relations`
- `/equations`
- `/theorems`
- `/open`
- `/chronology`
- `/sources`
- `/search?q=mobius`

The API uses Python's standard library only.
