# Mathematical Reference Layer

CFP-001 uses standard mathematical structures. The release does not depend on these references being bundled, but records them for external readers.

1. J. E. Hutchinson, "Fractals and self similarity," Indiana University Mathematics Journal 30 (1981), 713-747. Standard iterated-function-system/self-similar-set framework.
2. K. Falconer, *Fractal Geometry: Mathematical Foundations and Applications*. Standard reference for Hausdorff dimension, box dimension, projections, products, and self-similarity.
3. Standard algebraic graph theory/topology: for a connected finite graph, cycle rank `beta_1=E-V+1`; Z2 edge-sign configurations modulo vertex gauge are naturally described by first cohomology `H^1(G;Z2)`.
4. Standard linear algebra/inverse problems: identifiability of a linear latent state from stacked probes is equivalent to injectivity on the admissible difference space; kernel/nullity records unresolved directions.
5. Standard information theory: a many-to-one map may decrease distinguishability; exact recovery of erased information requires an injective restriction, auxiliary record, or decoder on a restricted code space.

These are mathematical interfaces. Their use does not validate MK43 physical claims.
