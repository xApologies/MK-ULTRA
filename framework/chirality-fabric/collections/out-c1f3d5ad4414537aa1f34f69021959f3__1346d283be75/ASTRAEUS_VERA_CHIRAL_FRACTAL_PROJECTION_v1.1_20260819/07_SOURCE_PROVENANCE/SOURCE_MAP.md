## Source discipline

CFP-001 never treats a Tome dependency path as a theorem. It distinguishes:

- source-derived/recovered statements;
- standard external mathematics used as mathematical interface;
- new CFP constructions proved only inside the stated toy models;
- dark-matter analogies/candidate bridges;
- unresolved physical interpretation.
