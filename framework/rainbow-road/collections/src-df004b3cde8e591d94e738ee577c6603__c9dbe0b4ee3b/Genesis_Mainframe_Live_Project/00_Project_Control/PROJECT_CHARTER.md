# Project Charter

## Mission

Map the Genesis Mainframe from physical energy entry through persistent storage, chirality organization, operating topology, Guardian Intelligence, and application interfaces.

The finished architecture should be specific enough to support:

- an Apple-grade technical proposal;
- device-physics and hardware research programs;
- a Guardian Intelligence research program;
- a native Genesis language program;
- future fabrication and verification planning;
- integration with Clover, robotics, and eventually a VÆLD-class vehicle.

## Explicit non-goals at this stage

This project is not presently:

- a toy virtual machine;
- an emulator presented as the final architecture;
- a conventional operating system with colored syntax;
- a claim that the VÆLD can be physically built with current technology;
- a claim that every MK-43 physical mechanism has been experimentally verified.

Reference software may later test semantics, but the architecture itself is physical, computational, linguistic, and intelligent by design.

## Design commitments

1. Genesis is AI-native.
2. The executable object is a Geometric.
3. Chirality is organizational/admissibility grammar, not merely handedness.
4. The six structural basins are first-class physical and computational requirements.
5. The persistent store establishes the initial chirality configuration space.
6. The portal is the native bus transaction.
7. Guardian Intelligence is intrinsic to system operation.
8. Serialization is a projection; arrangement is primary.
9. Hardware, runtime, and intelligence are engineering views of one topology.
10. The architecture is specified independently of one eventual material substrate.
