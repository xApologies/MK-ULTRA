# Genesis Language Architecture

## Role

Genesis is the native language through which:

```text
the architecture describes organization
the operating topology defines transformations
Guardian Intelligence interprets and manages the system
humans communicate intent and inspect results
```

## Semantic construction order

```text
Environment
  -> Boundary
  -> Occupancy
  -> Relationship
  -> Identity
  -> Persistence
  -> Resolution
```

## Language projections

### Human projection

Spoken/written Genesis and English explanations.

### Guardian semantic projection

Relationship-first structured meaning.

### Geometric projection

Machine-readable instantiated organization.

### Architect projection

Native transformation operators.

### Physical projection

Basin states and chirality arrangements in the fabric.

These are not separate unrelated languages.

They are resolutions of one architecture-native grammar.

## Constraint

Do not optimize the core representation for manual human coding when that would reduce explicitness, admissibility information, or Guardian interpretability.
