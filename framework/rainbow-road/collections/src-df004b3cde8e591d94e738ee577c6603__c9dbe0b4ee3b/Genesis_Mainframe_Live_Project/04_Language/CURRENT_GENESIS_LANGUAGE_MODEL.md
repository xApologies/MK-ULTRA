## Development method

```text
capability
  -> computational meaning
  -> invariants
  -> composition
  -> execution semantics
  -> notation
  -> implementation
```

The portal is the first handle because exchange of organized information is already known to be required.

Portal-first does not mean portal-only.

## Current central question

> What transformations must Genesis be able to perform on a Geometric whose organization is expressed through chirality and local structural-basin energy densities?

## Color-indexed portal discovery

A new working insight is active:

```text
Color is a discrete basin index shared by many
structurally distinct Geometrics.
```

Define:

```text
Color : Geometric -> Basin
```

Then a color class contains all Geometrics resolving into that basin:

```text
Gamma_k = { G | Color(G) = B_k }
```

A portal may be color-specific:

```text
P_k : Gamma_k -> Target
```

This allows the portal network to route, admit, preserve, or transform Geometrics according to discrete basin color while retaining the full internal Geometric as payload.

This is not yet final language syntax.

---

## Rainbow Road discovery

The color-indexed portal model now distinguishes:

```text
Portal
    one admissible transfer

Rainbow Road
    persistent composition of color-indexed portals
```

A Rainbow Road may preserve color, transform color, cycle, branch, or multiplex.

The full Geometric remains the payload.

Color indexes local route structure.

Chirality determines admissible continuation.

No final road syntax or basin traversal order is locked.
