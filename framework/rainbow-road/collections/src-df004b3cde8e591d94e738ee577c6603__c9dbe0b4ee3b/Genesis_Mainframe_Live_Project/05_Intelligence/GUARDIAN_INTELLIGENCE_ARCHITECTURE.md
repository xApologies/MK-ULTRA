## Guardian hierarchy

Working hypothesis:

```text
Root Guardian
  -> Fabric Guardians
  -> Portal Guardians
  -> Application Guardians
  -> Device/Interface Guardians
```

This hierarchy is an implementation decomposition, not a separation of the Trinity.

## Guardian safety laws

1. Never silently invent missing structural information.
2. Preserve unresolved status when Resolution is insufficient.
3. Preserve provenance.
4. Protect declared identity invariants.
5. Reject operations that exceed Bandwidth.
6. Maintain closure checkpoints.
7. Explain transformations in Genesis terms.
8. Permit human correction and canon updates.
9. Learn without silently rewriting root grammar.
10. Recover locally before escalating globally.
