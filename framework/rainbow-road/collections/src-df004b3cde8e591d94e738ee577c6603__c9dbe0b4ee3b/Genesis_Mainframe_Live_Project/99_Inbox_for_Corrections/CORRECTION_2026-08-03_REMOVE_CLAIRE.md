# Correction — Remove “Claire” from architecture examples

**Date:** 2026-08-03  
**Status:** Integrated

## Problem

“Claire” came from a conversational anecdote in which the user said, in effect, “we’ll call her Claire” while describing a child who preferred doing mathematics in colors.

It was not a canonical Genesis architecture term.

The assistant mistakenly promoted that placeholder into:

- a program name;
- a Geometric identity;
- a portal example.

## Correction

All architecture examples now use neutral names:

```text
Genesis_Portal_0
Payload
PayloadIdentity
PayloadPersistence
Payload_A_to_B
```

## Rule

Anecdotal names, conversational placeholders, and illustrative human stories must not be promoted into Genesis canon without explicit user approval.
