## Clone and large files

Install Git LFS before retrieving files tracked by this repository's `.gitattributes`, then run `git lfs pull` in the checkout. A successful ordinary Git clone alone does not establish that all LFS content was downloaded. On Windows, enable Git long-path support for this checkout; some preserved source collections have long internal paths.

```sh
git -c core.longpaths=true clone https://github.com/xApologies/MK-ULTRA.git
cd MK-ULTRA
git config core.longpaths true
git lfs install
git lfs pull
```

Use the supplied GR/QMO installation and test instructions in `api/gr-qmo`. Historical collection-specific tests retain their original scope and are not evidence that the entire framework has been independently validated.
